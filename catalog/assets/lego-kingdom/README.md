# 乐高视频二维动作来源

来源与采用的完整工作区版本见 [来源清单](SOURCE.json)。原工程只作为提取依据；独立工程附实际绘制、轨迹数据、字体与许可，不读取原工程或本机绝对路径。

同一种运动方式归入既有目录条目的示例。保留的内容是源程序绘制的二维图形和对应时钟；矩阵落入与路径光包只用一个组合保留其先后关系。录屏框、真人头像、原片音轨、品牌点阵字和可编辑三维场景未纳入。未用重新画的头像、界面或几何小屋替代它们。

## 使用边界

数字使用原 Oswald 字体，代码与等宽标注使用原 IBM Plex Mono 字体，字重文件随包保留。中文原 PuHuiTi 文件未提供随附许可，因此目前仍用目录既有思源黑体，中文外形与排版度量存在差异，不能称为完整视觉复刻。计时图的第一行品牌名称改为可编辑的“示例模型”；其余源图形、原文、读数和时间关系保留。示例数据用于展示，不构成对相关模型的性能声明。

九点引线标注按用户明确要求附原乐高王国背景：第一镜头46帧、第二镜头47帧，共93张1080×1440无损WebP图像，目录和独立导出均按动作帧同步取图；第46帧撤掉原标签并切入第二地形。背景来自用户项目的无声镜头，不含成片水印、配音或头像；它是图像背景，不是可编辑三维模型。该素材仅获本地接入授权，不据此声明可公开再分发。两段来源、逐帧映射和校验值见来源清单。独立源码可编辑文字、数值和图形，目录公开参数为播放速度。

## 随附许可

- 思源黑体 Regular、Bold：`catalog/fonts/`，SIL OFL 1.1，见 [许可](../../fonts/OFL.txt)。
- Oswald Light、Regular、Medium、SemiBold、Bold：本目录 `fonts/`，原字体内含 SIL OFL 1.1 声明，见 [许可](fonts/Oswald-OFL.txt)。
- IBM Plex Mono Light、Regular：本目录 `fonts/`，原字体内含 SIL OFL 1.1 声明，见 [许可](fonts/IBMPlexMono-OFL.txt)。
- React / React DOM 19.3.0：MIT，见 [React](../reel-extract/React-LICENSE.txt)、[React DOM](../reel-extract/ReactDOM-LICENSE.txt)。
- Remotion 4.0.532：按其专有软件许可使用，见 [原许可](../reel-extract/Remotion-LICENSE.txt)。

命令行导出会复制二进制字体；只有引线标注的乐高示例额外复制93张背景图。仅复制文字源码时，按独立工程说明运行素材准备程序，再运行 `npm run check:source` 核对包内素材。
