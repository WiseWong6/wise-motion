# 谱面、动作与软件来源

## 动作署名

“谱面光点跳跃”与“沿点跳跃留光”复刻自 [@言说心事](https://www.xiaohongshu.com/user/profile/6926ff85000000003702b1c1?xsec_token=ABiobWDdNSX_CX9Vf091D7iZ9SeSMSlAk4oyjghnynYPQ%3D&xsec_source=pc_search) 老师的教程。光点、跳跃、尾迹及光照程序由本项目制作与适配。

## 现行谱面

| 项目 | 来源与处理 |
| --- | --- |
| 旋律 | 《小星星》采用的法国古老旋律 Ah, vous dirai-je, maman，属于公有领域。历史见[莫扎特基金会作品记录](https://kv.mozarteum.at/de/work/zwolf-variationen-in-c-uber-4057)，该旋律已用于 1781—1782 年的变奏作品。这里只采用古老主题旋律，不采用现代编配或莫扎特变奏的伴奏。 |
| 编配与排版 | Wise Motion 重新编写简单二声部伴奏，以本项目代码绘制谱线、谱号、拍号、符头、符干和小节线。新排谱及数据按 Apache-2.0 提供。 |
| 范围与时长 | 前八小节、每分钟 80 拍，共 44 个音符事件；乐句 24 秒，入场 0.4 秒，尾段 1.4 秒。现行动作沿原定时间窗口截取预览。 |
| 文件 | score-clean.svg、score-data.json 及 notes-source.js 中的离线副本，由源码工程中的 `scripts/build-public-score.mjs` 同时更新。 |
| 被替换材料 | 当前分发文件不再包含《晴天》谱曲、Steven Law 编配或其派生音符。也不包含原 PDF、MIDI、音色库或演奏音频。 |

## 绘制与软件

Three.js 三维绘制程序按 MIT 许可使用，原许可见 [THREE-LICENSE.txt](../../THREE-LICENSE.txt)。其声明保留在离线绘制包中。当前排谱程序不依赖音乐字体或 Verovio，不发起网络请求。

光圈按当前谱面的符头路径绘制，落点坐标与时值来自同一份生成数据。光点与柔光丝由本地代码绘制。蝴蝶造型沿用项目原制作成果，其几何与绘制代码随包提供；原制作记录保留于项目维护资料。
