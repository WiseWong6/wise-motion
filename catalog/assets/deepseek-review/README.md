# DeepSeek 测评动效来源

从用户授权的自有测评工程提取搜索筛选与递送、创作卡片变剪辑轨道，以及开头的数据展示。保留1080×1440画板和30帧时钟；图形按当前帧计算，未用录像替代可编辑源码。原文件内容摘要见 SOURCE.json。

完整组合含本地原配音及对应音乐、搜索音效；独立动作无声。音轨混合边界见 AUDIO.json。未包含跨场景转场；没有新合成声音。

中文细体与粗体沿用思源黑体；网页字体与原字体的全部字形及排版表相同。英文和数字附原 Oswald Bold 字体。字体遵循 SIL OFL 1.1；React、React DOM、Remotion 依各自许可，自有绘制源码为 Apache-2.0。

数据来自原片示例，未核验为当前模型评测结论；帕累托曲线是解释性示意。复用者应替换为自己的有效数据，不应把示例曲线当作实测结果。
