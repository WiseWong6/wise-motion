# 分秒之间

机械怀表的三维概念发布片。使用 Blender 重建表壳、表冠、齿轮、夹板、轴承、螺钉、游丝与指针，以 Cycles 光线追踪渲染，再合成声音和视频。机械结构用于视觉设计与动画，未作为可制造、可校时的机芯工程验证。

## 直接查看和编辑

- `审核.html`：直接打开，播放视频与查看原尺寸画面；不需要服务器。
- `成片/分秒之间.mp4`：22 秒、1920 × 1080、24 帧/秒，包含原创双声道声音。
- `成片/整表.png`、`成片/机芯.png`、`成片/分层.png`：3840 × 2160 的独立渲染画面。
- `分秒之间.blend`：可编辑的完整工程，已打包字体与底板表面纹理。相机切换、分层拆解、摆轮与齿轮运动均在时间轴内。

Blender 安装在标准应用目录 `/Applications/Blender.app`，其他项目可直接使用；命令入口 `/opt/homebrew/bin/blender` 也已可用。打开工程后，从相机视角播放时间轴即可检查镜头。最终材质以 Cycles 渲染结果为准。

## 制作方法

所有表体和零件均为三维几何，包括表壳曲面、齿轮齿形、金属倒角、开槽螺钉、宝石轴承与蓝钢指针。底板使用前一轮由 Codex 内置图片工具生成的珍珠纹作为细微表面纹理，未使用生成的整表图片充当三维主体。其余金属、条纹、珐琅、灯光和背景由 Blender 场景计算。

镜头顺序为夹板微距、摆轮微距、整表亮相、沿轴线展开与合拢、整表收尾。全部使用原生三维逐帧渲染，没有用平面图缩放代替零件运动，没有插帧。

`源码/build.py` 负责场景、材质、摄影棚、灯光和动画；`movement.py` 与 `casework.py` 分别负责机芯和外壳；`render.py` 渲染静帧和动画；`sound.py` 制作声音；`compose.py` 合成视频；`review.py` 生成静态审核页。

## 重新制作

推荐双击根目录的 `打开与制作.command`，按菜单打开工程、重建或继续制作；可整体移动文件夹。完整操作见 `使用说明.md`。

在终端进入本目录后，也可以按顺序运行：

```sh
blender -b --python-exit-code 1 --python 源码/build.py
blender -b 分秒之间.blend --python-exit-code 1 --python 源码/render.py -- --stills --samples 96 --threshold 0.025 --scale 200
blender -b 分秒之间.blend --python-exit-code 1 --python 源码/render.py -- --samples 48 --threshold 0.05
python3 源码/sound.py
python3 源码/compose.py
python3 源码/review.py
```

动画渲染会跳过已有帧。修改工程之后若要完整重渲染，先将旧的 `帧序列` 目录另存或移走；不要混用不同模型版本的画面。合成脚本需要电脑已有的 FFmpeg（含 ffprobe）和 Python 3。只有重新生成声音的 `sound.py` 需要 NumPy；双击入口复用随项目保存的声轨，不需要此依赖。

`检查/` 保留工程、分层归位、相机切换、实际渲染、音轨与视频核对结果。只把实际通过的检查写入记录。旧版作品仍保留在上一级的 `高级制表` 与 `发布片` 目录。

Blender 官方运行程序及校验记录在 `工具/runtime.json`。运行原理参考 [Blender 官方 GPU 渲染说明](https://docs.blender.org/manual/en/4.5/render/cycles/gpu_rendering.html) 和 [采样说明](https://docs.blender.org/manual/en/4.5/render/cycles/render_settings/sampling.html)。
