# 获取完整 Blender 工程

npm 包保留播放与渲染所需的成片、声音和两张目录预览。修改三维模型或重新制作时，从 [Wise Motion 源码仓库](https://github.com/WiseWong6/wise-motion) 单独下载完整工程；Blender 模型、制作纹理、三张高清静帧、建模与动画程序均保留原文件，不在安装 npm 包时联网下载。

在准备存放工程的目录运行以下命令。目标 `wise-motion-source` 必须尚不存在；这里只取工程及声音目录，固定到当前模型和素材的来源提交，避免后续更新与素材清单不一致。

```sh
git clone --filter=blob:none --no-checkout https://github.com/WiseWong6/wise-motion.git wise-motion-source
git -C wise-motion-source sparse-checkout set --cone catalog/assets/precision-assembly catalog/assets/composition-audio/precision-assembly
git -C wise-motion-source checkout a71076415bcc20ff056908ccfea3d45407f4c73f
cp -n wise-motion-source/catalog/assets/composition-audio/precision-assembly/soundtrack.wav wise-motion-source/catalog/assets/precision-assembly/成片/分秒之间-声轨.wav
```

最后一条命令把共享声轨复制到原工程的制作脚本所需位置，已有同名文件不会被覆盖。Blender 工程位置：`wise-motion-source/catalog/assets/precision-assembly/分秒之间.blend`。同目录中的 `使用说明.md`、`制作说明.md` 和 `打开与制作.command` 提供打开、源码重建与渲染步骤。字体及各软件许可仍遵循原说明。

从目录复制了独立 Remotion 工程的用户，在该独立工程中执行：

```sh
node prepare-assets.mjs /完整路径/wise-motion-source
npm run check:source
```

素材准备程序只复制清单中的文件，核对每个文件的长度和摘要，并拒绝覆盖已有不同内容。完整源码仓库中的命令行导出仍会一次复制完整工程与素材；npm 播放和渲染组件不要求下载 Blender 工程。
