## 本次修正

本次修正的是行走朝向：旧版侧身图朝画面右侧，运动却沿手机斜向右下。现补齐朝右下的前侧俯视图，以及朝左上的后侧俯视图；前后脚的地面方向与去返路线对应，角色始终向前移动。没有旋转或镜像整只猫来凑方向。触碰快门改为依据新图真实前爪的位置计算横纵移动，停车点略向按钮靠近，避免前腿横折；倒地支点也使用当前视角的脚。快门坐标、路线总长和各动作时间保持对应。

工厂正本没有修改，副本中原始造型代码仍保留供核对；实际行走改用依据该设定补画的两个角度。每次脚掌落地后固定位置，抬脚时才移动到下一处；起步和最后一步缩短。

步态调整：保持原路线和时长，将原先每秒约八次的碎步改为每秒约四到五次的轻快小跑。缩短支撑段，留出收爪和前送的时间；侧面腿分段弯折，返程视角补上关节弯曲与身体的轻微起伏。脚掌末端保留厚度，最后几步错开落地收住，原来的脚点固定检查仍保留。

缺失的正面、斜后方、反向侧身和低头角度由内置绘图工具依据工厂 v10 定稿补齐。头、身体保持原图比例，腿部独立运动；转身使用相应视角，不能翻转整猫代替转身。补图属于原设定的视角延展，不能称为原稿的逐像素拷贝。

自拍先在 600 × 820 的普通画布中按正常比例排好两张头像，只做一次左右镜像，再把整张画面贴合手机四角。远侧人物倒置，近侧小葵正立；手机和倒计时不镜像。人物脸型、帽子、五官不再单独压扁。外部的距离、转向与低头动作同时决定屏幕里小葵的位置和朝向。

开场和去程的手机画面只有人物，没有小猫照片。小葵返程走入取景范围后才从画面下沿进入，结尾形成合照；造型核对图使用结尾自拍，封面与关键帧对照使用真实初始帧。

保留原布景、动作顺序和倒计时。录屏开头包含播放跳转，选用连续的第 122–586 帧；音轨也来自这段连续 7.75 秒。原片后半段的黑屏原因不能从录屏确定，本版没有增加脱离角色动作的定时黑色遮罩。

## 制作与核验

- `vendor/cat.js`：工厂代码副本，原路径与花纹保留。
- `cat-motion.js`：步幅、逐脚起落、起停和真实触碰快门。
- `view-puppet.js`：补充视角与腿部运动，头身等比绘制。
- `turn-motion.js`：各视角之间共用的逐脚转身落点。
- `film.js`：场景、角色、展平自拍与手机合成；视频及对照图使用同一套代码。
- `choreography.js`：原片对应的动作、倒计时和低头时序。
- `player.js`、`style.css`：统一播放控件。画面和音轨由同一视频时钟播放。
- [素材来源与提示要求](assets/generated/制作记录.md)、[去程朝向补图提示词](assets/generated/行走朝向补图提示词.txt)、[返程朝向补图提示词](assets/generated/返程朝向补图提示词.txt)：均使用 Codex 内置绘图工具。

```sh
node scripts/render.cjs
node scripts/review.cjs
node scripts/verify.cjs
node scripts/gait-compare.cjs
```

脚本使用本机已有的画布库与 FFmpeg，可用 `CANVAS_MODULE` 指定画布库；离线播放不依赖制作工具。检查覆盖真实绘制的头像比例、镜像次数、脚端位置、触碰按钮、原设定保留、拖回相同时间的一致性、视频帧数与音轨。造型与动作另外通过并排图、连续帧和正常速度播放复核，数值通过不等于用户已认可观感。

最终视频在本地播放器正常播放至结束，音轨解码比对一致。离线页的资源、代码和控件事件检查通过；自动浏览器因本地文件地址安全策略无法打开页面，因此没有声称完成真实浏览器操作验收。转身采用绘制好的几个角度逐脚过渡，仍存在离散视角切换，未声称达到连续三维旋转效果。

本轮朝向修正已重新导出并完成检查：465 帧、1860 个脚点采样、快门接触及开场无猫照片通过；去返程身体地面轴与实际行进方向的夹角约为 4.16° / 3.86°。已查看等比连续帧、低头段、造型与展平自拍，并在本地播放器完整播放新版，另核对了用户截图对应的约 1.8 秒画面。半速对照左侧为朝向修正前，右侧为本轮新版。
