# 小葵和我声音素材

[连续自拍音轨](continuous-audio.m4a)用于组合条目 `xiaokui-selfie-journey`，长度为 7.75 秒。它来自原录屏选用的连续第 122–586 帧对应声音，保留原音轨。

[来源记录](SOURCE.json)提供原文件位置与校验值；当前组合的起点、时长和音量见[组合声音清单](../SOURCE.json)。

在 Wise Motion 目录选择“小葵和我”，打开声音开关试听。组件默认包含声音，传入 `includeAudio={false}` 可关闭；暂停、定位、循环和倍速跟随组合帧时钟。

程序许可不覆盖第三方录音；录音权利须按其来源单独核对。
