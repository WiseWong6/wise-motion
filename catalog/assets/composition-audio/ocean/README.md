# 海面上的夕阳

油画质感的海上落日：3:4 与 9:16 双版本。太阳悬在海面上空，飞机荡着秋千缓缓入水，天色渐暗后星空浮现，配海浪混音。约 28 秒。

## 打开

双击 `index.html`（横版）或 `portrait.html`（3:4 竖版），本地离线运行。底部播放条：播放／暂停、进度、重播、倍速、声音开关与时间。

## 声音与授权

海浪混音与场景音效见 `audio/`；来源与许可记录见 `audio/CREDITS.md`。

## 结构

| 文件 | 用途 |
| --- | --- |
| `sketch.js` / `sound.js` | 时间驱动的确定性动画与音效 |
| `index.html` / `portrait.html` | 页面入口 |
| `scripts/export-warm-4k.cjs` | 确定性 4K 3:4 视频导出（离线音轨 + 逐帧渲染） |
| `tests/` | 自动检查 |
| `p5.min.js` | 本地绘图库 |

遵守上级目录的统一播放控件与项目约定。
