# 蒲公英 · 风过之处

跟随一粒蒲公英，穿过荷塘、麦浪、山林与云海，落地迎来新的生长。

## 打开

下载完整文件夹，双击 `index.html` 即可观看，无需安装或联网。请保持文件夹中的文件位置不变。

## 播放

- 点击画面中央的播放按钮开始，点击画面可暂停或继续。
- 拖动底部进度条，或点击场景名称跳转。
- 点击「配乐」切换音乐。
- 点击「全屏」进入沉浸观看，点击「退出全屏」或按 Esc 返回。
- 空格键暂停或继续，R 从头播放，F 切换全屏。

## 目录

- `index.html`：页面入口。
- `assets/css/`：页面样式。
- `assets/js/`：动画与播放控制。
- `assets/audio/`：配乐。
