# 小葵 · 把气球交给风

p5.js 绘制的 14 秒循环动画（3:4 画幅）。灰白小猫小葵驾驶白色敞篷车匀速前进，车尾 35 只彩色气球逐个脱落、随风飘走；气球全部离开后镜头逐渐落后，汽车驶出画面。

## 打开与操作

双击 `index.html`，本地离线运行。底部播放条：播放／暂停、可拖动进度、重播、0.5–3× 倍速、声音开关与时间显示；空格键切换播放。

## 声音

默认关闭。行驶、风声、35 次气球松绳与小葵的一声轻喵均在本地合成／播放，暂停、拖动、倍速与后台切换时保持同步。素材授权见 `assets/audio/README.md`。

## 结构

| 文件 | 用途 |
| --- | --- |
| `index.html` / `style.css` | 页面入口与统一播放条样式 |
| `scene.js` / `xiaokui-car.js` | 时间驱动的确定性动画（seek 不累积误差） |
| `sound.js` | 音效合成与事件调度 |
| `tools/export-3x4.cjs` | 确定性 3:4 视频导出（离线烘焙音轨 + 逐帧渲染） |
| `verify.cjs` / `verify-sound.cjs` | 静态检查 |
| `vendor/p5.min.js` | 本地绘图库 |

遵守上级目录的统一播放控件与项目约定。
