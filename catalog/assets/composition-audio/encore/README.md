# 雨中曲 · 返场声音素材

[配乐文件](climax.mp3)用于组合条目 `encore-full-journey`。当前组合播放音轨前 24.543 秒；各条目的起点、长度和音量见[组合声音清单](../SOURCE.json)。

录音来自原工程已有《雨中曲》音频的 36.90–65.42 秒，保留原速与原增益。[来源记录](SOURCE.json)保留原文件位置与校验值；[原播放代码](player.js)和[原编舞代码](choreography.js)供核对声音与动作关系。

在 Wise Motion 目录选择“雨中曲·返场完整编舞”，打开声音开关试听。组件默认包含声音，传入 `includeAudio={false}` 可关闭；暂停、定位、循环和倍速跟随组合帧时钟。

程序许可不覆盖第三方音乐或录音；本目录未提供该歌曲的再分发授权证明，使用音乐前须另行核对相应权利。
