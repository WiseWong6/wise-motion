# 银河素材

- `galaxy-sky.png`：原创生成的银河底图（2026-09-22），1086 × 1448，约 2.3 MB。保留生成结果原图，没有裁切、改色或拉伸。
- `galaxy-stars.js`：从底图读取的 320 颗亮星坐标、颜色、亮度与周围星云亮度，供飞行落点、银河亮部选择和闪烁使用；另有 33 处星带中轴及两侧宽度，让银河沿原图走向从中间向两侧渐显。运行 `python3 scripts/sample-galaxy.py` 可重新读取；该脚本需要 Pillow，只分析像素并输出坐标，不改动图片。
- 构图参考：[ESO 的银河拱桥照片](https://www.eso.org/public/images/potw2132a/)，摄影署名 ESO / M. Zamani。页面使用原创生成底图，未复制这张照片的像素，也不将生成结果作为真实观测资料。
- 本地图像通过普通图片标签对象加载，再由独立画布渐显；文件直开，不需要服务器。输入框、物品、水波、光束与星芒由页面实时绘制。
