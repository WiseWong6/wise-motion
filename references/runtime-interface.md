# 样例的统一播放接口

所有标准演示采用 640 × 360 的逻辑画布，也就是 16:9，在容器中等比例缩放。演示通过固定时间计算画面，不使用随机数或真实鼠标操作驱动，方便以后交接到视频制作流程。立体翻页书另外提供可切换的交互体验，其纸面绘制与固定演示共用同一实现。

## 画面内的字号

字号按 640 × 360 画板中的用途统一：密集刻度 10、标签与说明 12、正文与小读数 16、卡片标题 24、中标题 32、大标题 48、主读数 64。容器整体缩放时，文字随画板等比变化。英文和数字使用 Oswald Bold，中文正文保持思源细体；原色插画物件中的原界面与图形文字继续保留。

`MotionKit.type` 保存字号，`prepareStage()` 为预览、缩略图和独立导出提供对应的 `--type-*` 样式变量。图形源码整体缩小时，用 `MotionKit.textSize('caption', scale)` 补偿标签，避免图表读数过小；只在建立画面时计算，不逐帧测量。词云收拢、主体缩放和字形粒子本身的大小变化仍按动画执行。

## 统一动作节奏

单个入场、强调和简单标注的主要动作使用 600 毫秒，多项展开、描线和基础数据使用 1200 毫秒，多阶段变化与回弹使用 1800 毫秒，讲述与复杂图表使用 2400 毫秒。完整组合保留 3600 毫秒的主要过程。以上单次演示统一等待 150 毫秒后起动，完成后静止 450 毫秒；总长包含等待与停顿。物理回弹、错峰间距和先后关系随过程一起调整。

`registry.json` 中的 `timing` 记录原设计时长、原缩略图时刻、原动作起止和目录内的新起止。`MotionKit.createRenderer(stage, definition)` 在建立画面时对应这两个时间区间，并把原设计时长传给源码工厂；固定毫秒和按总长比例绘制的效果因此共用同一节奏。原工厂继续保持原设计时钟，不直接按目录的新总长调用。主播放器、静态缩略图和导出的完整页面均经同一入口绘制，末尾停顿不挤掉尚未完成的动作。

循环效果单独设置周期，不添加开头或末尾停顿；累计时间保持连续。快切、已放慢的双向卡片传送带、固定帧率逐格运动、词云阅读过程、翻页书和原色插画继续保留各自的特殊节拍。历史配方的原作计时保持原样。速度控件的默认一倍就是目录的新节奏，调整倍速不会改变定位时刻的画面。

## 使用方式

按 `catalog/index.html` 的脚本顺序加载：Anime.js、本地数据、匹配与播放程序、所需分类的效果脚本。页面为普通本地脚本，不使用跨文件模块，也不读取远程资源。

```js
const effect = MotionRegistry.effects.find(e => e.id === 'dual-scroll');
const player = MotionRuntime.create(container, effect, {
  autoplay: false,
  onUpdate({time, duration, paused}) { /* 更新控件，单位毫秒 */ }
});
player.play();
player.pause();
player.seek(2400);
player.setSpeed(0.75);
player.restart(false);
player.destroy();
```

| 方法 | 行为 |
|---|---|
| `play()` | 从当前时间播放。一次性效果已经结束时，从头开始。 |
| `pause()` | 保留当前画面并暂停。 |
| `restart(shouldPlay = true)` | 重置到起点；默认继续播放，可传入 `false` 保持暂停。 |
| `seek(ms)` | 定位到本周期中的毫秒数，超过区间时限制到起止点。不会改变暂停状态。 |
| `seekElapsed(ms)` | 按累计播放时间定位，循环效果保留已经过的周期和仅首次发生的入场。用于循环动作的精确定位；重播仍从头开始。 |
| `setSpeed(value)` | 同一效果调整到 0.5–2 倍速度，保持动作结构。 |
| `setEase(name)` | 调整允许的速度变化。连续滚动固定匀速，不接受改变持续性的曲线。 |
| `destroy(preserve = false)` | 取消计时器、停止尺寸监听并释放画面；传 `true` 可留下静态画面，不能再次播放。重复调用安全。 |

可读取 `currentTime`（本周期时间）、`elapsedTime`（累计时间）、`paused`、`speed`、`destroyed`。错误的非有限时间或速度会报错，不能进入不可复现的状态。运行状态通过 `MotionRuntime.instanceCount` 和 `runningCount` 读取；`disposeAll()` 释放当前所有实例。

需要载入本地字形数据或图片的工厂，可提供 `render.ready` 准备完成的承诺。播放器的 `ready` 成功返回 `true`，失败或提前销毁返回 `false`；`preparing` 表示仍在准备，`error` 保存准备失败的原因。准备期间计时器不前进，播放操作只保留意图，暂停取消意图，定位与倍速保留最新值；完成后恢复该时刻，再按最后的播放意图继续。此时 `paused` 和运行实例数按用户的播放意图计算，便于按钮、页面隐藏和相关动作弹窗正确暂停。失败会在画板显示原因，迟到的准备结果不会复活已销毁的实例。已有同步工厂保持原行为。

## 同一动作的示例样式

有多个原作示例的普通动作在 `variants` 中记录各自说明、时长与代表时刻，目录仅保留一个条目。`MotionKit.resolveVariant(definition, variantId)` 返回所选示例的有效定义；播放器和绘制入口也会按 `variant_id` 解析，未指定时使用第一项。切换样式先销毁旧实例，再从头播放；提示词和复制代码保留当前样式。

组合的 `actions` 继续引用动作名称，通过 `action_variants` 指定对应的示例。相关动作弹窗直接打开该示例并自动播放，仍可切换其它样式；主组合的图形和进度不变。

## 固定演示顺序与循环

- 所有源码工厂返回 `render(time, options)`；只根据本周期时间、总长、速度曲线与实际经过时间计算当前画面。
- 工厂有异步本地素材时，标记 `factory.requiresPreparation = true`；静态缩略图按队列建立绘制器，等待 `render.ready`，只画代表时刻后释放。缩略图定义传入 `poster_only: true` 与 `poster_time_ms`，供工厂跳过完整播放预热。工厂须在准备期间记录最新定位，销毁时取消自身待完成绘制；普通脚本和图片仍可由文件直接打开。
- 需要独立绘制资源的工厂还提供 `render.destroy(preserve = false)`；播放器销毁时调用它，缩略图绘制后传入 `true` 留下静态画面并释放资源。螺旋丸与电弧的光效画布先复制静态像素，再释放光照缓冲和绘制上下文，不在左栏保留活动绘制器。
- `options.elapsed` 为播放至今的时间，跨周期累计。双排滚动只在最初入场一次，不会每轮重新飞入；手动回到 0 毫秒会重新展示入场。
- 绘制器可声明 `render.frameRate`，以有限正数指定该实例的每秒更新次数；未声明的实例沿用默认频率，不改变全局时钟。`options.playback` 仅在自动播放更新时为 `true`，手动定位、调节曲线和准备完成后的恢复为 `false`。原片采用固定帧格时，播放按完整片段的起点对齐帧格，手动定位和末帧仍保留精确时间。
- 交互样例“界面操作反馈”按指针移到按钮、按下、处理、完成的固定顺序演示；没有隐藏的真实输入依赖。
- 主预览、相关动作弹窗和复制保存的页面默认从头自动播放，不根据系统动效偏好降级或暂停，不显示相关提示或开关。手动暂停、时间定位和已保存的暂停状态继续有效。目录页面隐藏时暂停；再次可见时只恢复隐藏前正在播放的效果。切换样例或离开页面会释放实例。目录收起、搜索或筛选保留当前预览。
- 目录显示名称与静态缩略图，不创建动画实例。标准参考用自己的绘制函数画一帧；历史参考使用原作图片、单帧绘制或静音视频定位。历史绘制器画完即释放，列表移除和离开页面时取消未完成的绘制并释放视频。中间常驻一个预览；定义中的代表时刻仅用于静态缩略图，不代替从头播放。
- 标准动作右侧“代码”由选中定义和当前参数生成完整本地页面，保存为源码包根目录的 `demo.html` 后加载现有普通脚本。页面、提示词与说明共用同一份定义，不另外维护效果描述。

## 扩充效果

立体翻页书源码位于 `catalog/effects/dither-book.js`。通过 `MotionRuntime.create()` 使用时保持固定演示，可在定义中传入 `paper_settings: {padding:10,radius:20,crease:11}` 指定图片留白、圆角和书脊阴影。右侧复制代码保留当前三个数值。

如需真实交互，可调用 `WiseDitherBook.create(container, {interactive:true, settings:{padding:10,radius:20,crease:11}})`，得到 `next()`、`prev()`、`restartIntro()`、`setSettings()`、`pause()`、`resume()` 和 `destroy()`。方向键只作用于书本内；翻页中拒绝连续重入，销毁时取消动画帧和事件。工作台切回时间演示时恢复原演示位置和节奏；窗口隐藏、切换动效或离开页面会暂停或释放交互。主播放实例计数仅统计固定演示，真实翻页帧由书本控制器释放。

历史配方使用 `MotionHistoryRuntime.create(root, definition, {caseId, onUpdate})`，提供播放、暂停、重播、定位和倍速等控制方法；原作曲线保持固定。还可读取 `duration`、`entry` 和等待 `ready`，分别获得本案例的预览总长、案例数据与加载完成状态。切换案例要先销毁旧实例，异步加载迟到时也会释放绘制器。视频强制静音；原素材与绘制脚本按需引用，不纳入自有示例许可。实例计数与全部释放由 `MotionHistoryRuntime` 提供。复制历史代码包含实际实现文件；按文件标题保留相对目录，并准备输出中列出的依赖包和素材输入。

`MotionHistoryRuntime.poster(canvas, entry, data, {isCurrent})` 用原案例绘制器画单帧，并复制到目标画布后释放绘制器；不建立播放计时器。`isCurrent` 用于阻止被移除卡片的迟到绘制。图片缩略图直接引用原文件，原片缩略图使用暂停且静音的视频定位，不生成新的图片资产。

1. 在统一定义 `catalog/registry.json` 中记录中文名称、用途、对象、行为标签、阶段、禁项、参数、来源与许可。先保留组合原实现，从实际图形和绘制函数拆出子动作，再核对已有动作；真正一致才复用，缺失项登记为独立动作。组合通过 `actions` 引用这些条目，工厂的 `breakdown` 声明实际层、动作关联和时间区间，`data-layer` 只供主画面逐层对照。相关动作弹窗直接建立独立工厂并自动播放，不用整段组合隐藏图层代替拆解。跨文件共用函数时，在 `source.dependencies` 按先后顺序列出所需效果脚本，复制代码会一并加载。
2. 在相应普通脚本里注册 `MotionFactories[id]`，返回能反复定位的画面函数。所有位置、文字、颜色、透明度应由当前时间完整确定，不能依赖之前播放到了哪一帧。
3. 保持固定演示顺序；不添加联网、随机数、页面外事件或不可取消的资源。
4. 运行 `node scripts/build.mjs` 和 `npm test`，检查定义、关系、路径、许可、定位可重复性和资源释放。

复杂书法与材质演变的轮廓、固定粒子、局部缓存和播放准备，见 [精修方法](material-refinement.md)。素材文件在定义的 `source.assets` 中列出，固定字形数据按需用本地普通脚本载入，复制页面保留整个源码包的相对目录。

本接口是动作参考交接，不承诺视频渲染器兼容，也不在本版提供成品视频输出。
