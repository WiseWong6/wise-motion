# 文字漂移收拢

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：文字漂移收拢
目的：先让模糊反馈形成可阅读的词云，再收拢到上方，为接下来的内容留出空间。
对象：一个云朵轮廓、手工编排的十三个吐槽词
动作阶段：
1. 云朵淡入，十三个词在各自的位置错峰出现，保持大小层次，文字完整位于云形内。
2. 云朵轻微呼吸，每个词按自己的频率小幅漂移，留出阅读时间。
3. 同一组词同步收紧词距与字号，随云朵缩小上移，最终停在上方。
节奏：5.40 秒完成一次；1 倍速度；匀速。按原成片的两段视觉时钟演示：约一秒完整出现，约四点一五秒开始上移收拢、四点八九秒完成；五秒后停止漂移，总长五点四秒。
触发与联动：词云先独立阅读，随后在下一段内容到来前整体收拢到上方；目录用固定时间表，可暂停与定位。
现实类比：把散开的便签先放在面前看清，再轻轻收成一束移到上方。
需要保留：保留原云形、十三词手工编排、中心绿色重点、大小层次和独立漂移频率；所有词在漂移与收拢全过程完整位于云形内，彼此保留阅读空隙；上移、词距与字号收紧同时发生，呼吸与漂移幅度随收拢减弱，所有词保持身份。
明确排除：不把各词漂移改成整组一起摆动，不重新自动排词，不在收拢时换字或删词；不带原整页背景、标题、字幕、箭头、回应图及扫光。
对应参考：本地目录「文字漂移收拢」
源码：catalog/effects/history-patterns.js 中的 word-cloud-lift
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：依据本机动效教程当前正本的云形、手工词位、主题和实际成片视觉时钟适配，整体等比缩到目录横向画板。保留云对象与手工编排，配色跟随统一主题，中文细体、英文与数字使用 Oswald Bold；为容纳全文，将原动作公式的字号等比例缩至 78%，右侧长词向内移 56 个设计单位，保留同步收紧与独立漂移，不复制影片运行器后续的统一字号替换。只提取词云主体，上移完成后停止，不导入原字体、声音或后续回应图。 画面统一采用展示片时间线的近黑/暖白与少量彩色强调，白天按同一色相适配；原几何与动作关系保留。

## 调整方式

播放速度：0.5–2 倍。
按原成片的两段视觉时钟演示：约一秒完整出现，约四点一五秒开始上移收拢、四点八九秒完成；五秒后停止漂移，总长五点四秒。

预览定位：2300 毫秒。固定演示总长：5400 毫秒。
