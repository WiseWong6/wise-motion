# 立体字母错峰落定

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：立体字母错峰落定
目的：四个厚实彩色字母错峰下落，着地压缩回弹，并压出向外传播的地面波纹。
对象：WISE四个实体字母与承托它们的密集胶囊地面
动作阶段：
1. 四字分别从各自落点上方进入，依次在0.34、0.51、0.68、0.85秒落地。
2. 每次落地伴随纵向压缩、横向鼓起、轻微倾转与衰减回弹；对应地面压陷。
3. 脚下波纹向外传播并衰减，四字在1.55秒前稳定。
节奏：1.55 秒完成一次；1 倍速度；匀速。完整演示1.55秒，四字间隔0.17秒着地；整体倍速保持先后关系。
触发与联动：打开后按固定时间播放；支持暂停、重播、时间定位与整体倍速。
现实类比：四颗饱满糖果依次落在柔软垫面上。
需要保留：四次接触时刻、按实际字形底部定位、保体积缩放与倾转回弹；保留奶黄胶囊的受压与波纹。
明确排除：不加载银球与MOTION字母，不把字面高光替换成平面渐变，不把地面响应提前到接触前。
