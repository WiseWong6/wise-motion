# 黄金矩形递归生长

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：黄金矩形递归生长
目的：复用黄金矩形递归生长的实际几何、连续时序与画面质感。
对象：暖色光点、深浅星点、瀑布坐标网格、黄金方格、字符雨幕、三处痛点文字、打铁花、波次网格与递归黄金图案
动作阶段：
1. 0至6.2秒：瀑布网格从中心建立，1、1、2、3、5、8格方块逐次拼接、内侧依次扫描，镜头两秒快速放大。
2. 6.2至14.33秒：字符雨幕流动与地震反弹；三条动作线延伸、停顿、打出铁花；缩小后原有黄金方格重现。
3. 14.33至21.13秒：同一团铁花持续存在，黄金矩形按父子关系接续、递归分割；网格波次传播，图案加速长满画幅并停留。
节奏：21.13 秒完成一次；1 倍速度；匀速。固定演示21.133秒，沿用组合0.000至21.133秒的节奏；播放速度可调。
触发与联动：打开后播放完整组合，可暂停、重播和逐时刻定位；组合拆解支持单独查看与逐层叠加。
现实类比：光点建立瀑布网格与黄金方格，镜头进入字符雨幕；亮线蓄势打出铁花，回缩后的原图形持续递归生长为满幅图案。
需要保留：21.133333秒、30帧每秒、634个采样；末段1.5倍生长。第一块方格始终从中心开始；2002个黄金矩形、9383个方格及弧线均依父级关系延伸，已出现的主弧线和铁花保持到最后。
明确排除：不使用原片图像，不随机重排，不让弧线越出所属方格，不把完整组合伪装成单个动作。
对应参考：本地目录「黄金矩形递归生长」；所用动作：瀑布网格黄金绘入、黄金方格中心放大、字符雨幕震动、亮线蓄势打铁花、黄金方格回缩、铁花持续绽放、网格起伏黄金生长、星点错峰闪烁
源码：catalog/effects/point-domain-flow.js 中的 point-domain-flow-sequence
来源与许可：原码提取与接入，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：图形与文字是可替换的示例；保留格内延伸、父子接续和当前时间可重现的动作关系。
