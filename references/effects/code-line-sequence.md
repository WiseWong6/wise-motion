# 行号随代码逐行输入

动效说明：行号随代码逐行输入
目的：四行原代码以每秒 38 字逐字写出，每行结束停顿 0.1 秒再写下一行；左侧行号与对应行一起显现。
对象：四行紫色代码、两位数字行号
动作阶段：
1. 第一行行号显现，代码按固定字速写出。
2. 每行完成后停顿 0.1 秒，再开始下一行；单双行保留原紫色区别。
3. 四行全部保留，没有输入光标或额外窗口。
节奏：3.50 秒完成一次；1 倍速度；匀速。目录从原场景 1.4 秒起，原 1.6 秒开始第一行；只是平移起点，不压缩字速。
触发与联动：按固定时间表播放，可暂停、重播和任意拖动定位。
