# 圆心发射与枝干光流

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：圆心发射与枝干光流
目的：把一个中心向多个要点传递的过程连接成完整动作。
对象：圆形发射源、两圈涟漪、三条曲线枝干、沿线亮尾与光团、三张端点卡片
动作阶段：
1. 圆形中心出现，两圈涟漪错相向外扩散，三条枝干依次长出。
2. 亮尾沿已长出的枝干流动；较强光团依次从圆心边缘发出，抵达端点后卡片显现。
3. 已到达的枝干变为实线，三张卡片保留；涟漪和辉光退去后整组停稳。
节奏：6.00 秒完成一次；1 倍速度；匀速。开头停留零点一五秒，主体五点四秒：三条枝干错峰长出，三个光团依次抵达，末尾静止零点四五秒。播放速度整体调整。
触发与联动：打开预览后按固定顺序播放；可暂停、重播和任意定位。
现实类比：一个圆形发射源把信息沿三条枝干送出去，接收位置逐个显出卡片。
需要保留：中心固定为圆形；涟漪、枝干与发射光点共用中心，枝尖、亮尾和光团共用同一曲线；卡片只能在对应光团抵达后显现。
明确排除：不要恢复胶囊或把三条枝干改为单向下落；不要让光点领先于尚未长出的路径，也不要提前亮出卡片。

源码：catalog/effects/radial-branch-flow.js 中的 radial-branch-flow
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
