# 面积曲线推进

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：面积曲线推进
目的：以连续面积曲线展示相对信号强度，读数与曲线端点同步变化。
对象：三十二个采样点、半透明面积、末端圆点、强度百分比与采样窗口
动作阶段：
1. 闭合细框和强度读数显现。
2. 曲线从左向右展开，半透明面积跟随填充。
3. 曲线沿最近1.8秒的窗口推进，锁定后变红并趋于稳定。
节奏：3.00 秒完成一次；1 倍速度；匀速。总长3秒，等待0.15秒后开始，末尾静止0.45秒；同一输入时间生成相同曲线。
触发与联动：打开后按固定时间演示，可暂停、重播及任意定位。
现实类比：一条带半透明填充的走势曲线持续推进，末端亮点和百分比始终对应。
需要保留：明亮银白#e5ebf2与纯白高光，锁定后采用红色#ff434d，背景近黑#060709。组合面板左右各留10，独立卡面左右各留12，标题仅在组合中显示。组合内同样保留四边闭框。32个采样点显示最近最多1.8秒的数据；0.4至1.15秒完成横向展开，纵向映射0至100%的相对强度；当前读数取末端采样值，曲线下方以顶部较亮、底部透明的渐变填充；2.72秒后当前强度稳定为95%。
明确排除：不混入其它仪表，不拉伸低分辨率画面，不用实时随机数；保持可暂停、回拖和重播。 不显示面板标题，不留下单侧缺边的外框。

## 调整方式

播放速度：0.5–2 倍。
总长3秒，等待0.15秒后开始，末尾静止0.45秒；同一输入时间生成相同曲线。

预览定位：1700 毫秒。固定演示总长：3000 毫秒。
