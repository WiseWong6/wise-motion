# 窗外实验树

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：窗外实验树
目的：原实验树的盛放插画，保留六色真实花簇、原枯枝树形与精确接枝，可切换枯枝状态。
对象：原枯枝树、六色真实花簇与沿枝长出的细花梗
动作阶段：
1. 沿用原实验树的树形与枝段。
2. 盛放状态保留六色花簇、花位和接枝。
3. 保持原固定姿态，可切换枯枝状态。
节奏：3.00 秒完成一次；1 倍速度；匀速。盛放和枯枝保持静态。
触发与联动：打开后查看；可暂停、重播与定位。
现实类比：原实验树的盛放插画，保留六色真实花簇、原枯枝树形与精确接枝，可切换枯枝状态。
需要保留：保留原实验树的2017条枝段、固定花位、六种真实花朵、花托和接枝关系、连续开花与前后遮挡。
明确排除：使用包内固定素材与数据，由当前播放时间决定画面；原作工程不参与运行。
对应参考：本地目录「窗外实验树」；所用动作：花簇沿枝接续盛开
源码：catalog/effects/scene-window.js 中的 window-experiment-tree-illustration
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：逻辑画板720×960，使用1440×1920高清画布等比呈现。树与花使用透明背景，保留原始位置与比例。

## 调整方式

播放速度：0.5–2 倍。
盛放和枯枝保持静态。

预览定位：1500 毫秒。固定演示总长：3000 毫秒。

## 源码与使用

- [原码提取与接入源码](../../catalog/effects/scene-window.js)，注册名称：`window-experiment-tree-illustration`。
- [统一播放接口](../runtime-interface.md)，可播放、暂停、重播、定位时间和释放资源。
- 效果参考 自有“窗外”实验树原作。
- 从自有“窗外”现行实验树迁入原枝形、花位、花期、枝条和花朵绘制，以及六色花朵、胡桃木窗框与树皮素材。原作只读；保留原1.4倍播放速度，固定两倍像素密度，仅替换页面播放入口。出处和原字节校验见素材目录 SOURCE.json。许可为 Apache-2.0。第三方 Anime.js 保留 MIT 许可。

所用动作：[花簇沿枝接续盛开](window-flower-bloom.md)。
