# 烟圈翻卷

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：烟圈翻卷
目的：将螺旋丸视频中的烟圈粒子作为可独立播放、定位和复制的图形参考。
对象：烟圈、环管剖面、固定身份的细粒子
动作阶段：
1. 粒子烟圈从淡到清晰。
2. 每个粒子保持环心方位，在环管的小剖面内翻卷。
3. 保持同一烟圈轮廓，末尾停住。
节奏：3.00 秒完成一次；1 倍速度；匀速。固定三秒：前三百毫秒显现，图形运动至二点六秒，末尾保持四百毫秒；只调整整体速度。
触发与联动：打开预览后按固定时间表演示；可暂停和定位。
现实类比：细小粒子围成有厚度的烟圈，沿环管剖面持续翻卷。
需要保留：固定粒子身份、原环径与厚度、剖面翻卷方向及细粒子层次；不把小剖面翻卷替换成整环转盘。
明确排除：去掉原片纸底、字幕、人物、章节文案、全页辅助标尺与声音；只保留图形，使用目录自己的底色。
对应参考：本地目录「烟圈翻卷」；所用动作：粒子环面翻卷
源码：catalog/effects/rasengan-illustrations.js 中的 smoke-ring-illustration
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：提取本机螺旋丸原工程的几何、固定粒子与短窗轨迹；在目录十六比九画板内等比居中，石墨线随明暗主题，螺旋丸与电弧保留原蓝色家族。

## 调整方式

播放速度：0.5–2 倍。
固定三秒：前三百毫秒显现，图形运动至二点六秒，末尾保持四百毫秒；只调整整体速度。

预览定位：2600 毫秒。固定演示总长：3000 毫秒。
