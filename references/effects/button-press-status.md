# 按钮按压换态

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：按钮按压换态
目的：展示按钮按压及处理阶段的文字反馈
对象：一个按钮及其状态文字
动作阶段：
1. 按钮按正弦节奏缩小至原尺寸的百分之九十五点五。
2. 按钮恢复尺寸，文案由开始整理改为正在整理。
3. 按钮保持尺寸，文案最终改为整理完成。
节奏：2.40 秒完成一次；1 倍速度；匀速。约零点一五秒开始，主体动作 1.8 秒，末尾保持零点四五秒；播放倍率整体调整。
触发与联动：打开预览后按固定顺序播放；可暂停、重播和定位时间。
现实类比：按钮接受一次操作，再通过文字报告状态
需要保留：保留一次轻压回弹，以及恢复后、完成时两个明确的文案切换时刻。
明确排除：不增加扩散圆环，不把按钮变形成面板，不额外创建指针或进度条。
对应参考：本地目录「按钮按压换态」
源码：catalog/effects/compositions.js 中的 button-press-status
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：独立示例只创建本动作所需对象，绘制函数与原组合共用；保留原对象样式、轨迹和阶段关系，目录时长按原时间段等比换算。

## 调整方式

播放速度：0.5–2 倍。
约零点一五秒开始，主体动作 1.8 秒，末尾保持零点四五秒；播放倍率整体调整。

预览定位：284 毫秒。固定演示总长：2400 毫秒。

### 可替换内容

通过组件 `content` 或分镜 `effect.content` 为当前镜头赋值；字段含义与字体、宽度限制见 [组件说明](../../REMOTION.md)。默认内容如下：

```json
{
  "states": [
    "开始整理",
    "正在整理",
    "整理完成"
  ]
}
```

- states（按钮三个阶段）：3–3 项，每项最多 12 字。
