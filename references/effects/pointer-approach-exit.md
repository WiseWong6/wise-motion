# 靠近淡出

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：靠近淡出
目的：表现一次模拟操作前后的指针移动
对象：一个箭头指针
动作阶段：
1. 指针从画面右下方开始移动。
2. 指针到达目标坐标后保持位置。
3. 指针在目标位置逐渐淡出。
节奏：1.80 秒完成一次；1 倍速度；末尾减速。约零点一五秒开始，主体动作 1.2 秒，末尾保持零点四五秒；播放倍率整体调整。
触发与联动：打开预览后按固定顺序播放；可暂停、重播和定位时间。
现实类比：指针靠近操作位置，完成示意后离场
需要保留：保留从右下方向目标靠近的直线路径、到达后的停留和随后淡出。
明确排除：不添加点击缩放、轨迹回放或其他界面对象。
对应参考：本地目录「靠近淡出」
源码：catalog/effects/compositions.js 中的 pointer-approach-exit
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
