# 笔画接续成字

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：笔画接续成字
目的：用书法笔画的接续与组合表现字形建立，保留长竖笔和墨迹厚薄。
对象：居中的书法矢量图形，主要墨迹位于横向160–472像素范围；37个固定书法姿态、每姿态7档固定灰墨、静态纸纹及角落小注。
动作阶段：
1. 0–0.63秒，墨迹从空白中出现，按选定轮廓形成横笔、弧笔与回转结构，保持实际墨色层次。
2. 0.63–1.73秒，主要轮廓短暂维持后快速接续；首部逐渐成形，相邻姿态以透明画布加权混合。
3. 1.73–2.50秒，长竖笔完整保留，首部与下方走之笔接成道字，角注在1.73–1.85秒显现，终点保持完整字形。
节奏：2.50 秒完成一次；1 倍速度；匀速。总长2.50秒，按每秒30个画面刻度取相邻姿态；0.63–1.10秒主要轮廓维持、笔锋小幅变化，1.73–1.85秒角注出现，1.80秒维持完整竖笔，不额外加入统一缓动。
触发与联动：打开预览后按固定顺序播放；可暂停、重播和定位时间。
现实类比：浓淡墨迹一段段接上，逐步组成同一个完整字形。
需要保留：保留37个固定姿态的顺序、7档墨色与细部孔洞；相邻画面的权重分别为1-p和p，避免长竖笔向小墨点塌缩；最多缓存3个区域姿态，保持纸纹静止和实际短暂停留。
明确排除：不以逐字打字或细线描画替代书法；不把不对应的碎墨强行连接变形，不每帧重算笔画对应关系，不删除长竖笔或缩成规则方块。
