# 输入框逐字写入

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：输入框逐字写入
目的：提取原片中输入框逐字写入的具体主体、造型与时间关系，独立复用并能与原组合逐层对照。
对象：原中文提示词、三行排版、光标与原输入框
动作阶段：
1. 界面先落定，光标在空输入区域闪烁。
2. 0.9–4.5 秒按原顺序写入 110 个字符，每字在 0.12 秒内上抬 6 像素并显现。
3. 文字停在三行完成态，保留菜单和工具，等待发送。
节奏：4.80 秒完成一次；1 倍速度；匀速。4.8 秒，包含原 0.9 秒起笔与 3.6 秒书写。
触发与联动：打开后播放；可暂停、重播和任意定位。
现实类比：原提示词按固定节拍写入三行，每个新字从略低处显现，细光标跟随。
需要保留：原 110 字内容、原 21.5 像素字号与逐字落点、885 像素换行阈值、36 像素行距和原光标位置。
明确排除：不改成整行淡入，不重排为单行，也不缩写提示词。
对应参考：本地目录「输入框逐字写入」
源码：catalog/effects/reel-prompt-outro.js 中的 prompt-chinese-type
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：保留原深色输入界面和文字；独立动作到 4.8 秒结束，不追加发送和飞字。 深浅模式均保留该段原深色画面。 普通英文与数字按目录规范使用 Oswald Bold，中文及混排正文用 Light；原逐字落点与换行保持，片尾 CLAUDE 主字是造型轮廓例外。
