# 文字逐字亮起后落色

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：文字逐字亮起后落色
目的：中文依次显现，每字先亮暖色并带光晕，随后落回正文色；英文随后按词出现。
对象：文字逐字亮起后落色
动作阶段：
1. 建立对象与空间关系。
2. 中文依次显现，每字先亮暖色并带光晕，随后落回正文色；英文随后按词出现。
3. 保留该阶段的落定或离场结果。
节奏：4.80 秒完成一次；1 倍速度；匀速。本示例4.8秒；帧号直接换算局部时间，支持倒放定位和重播。
触发与联动：打开预览后按固定顺序播放；可暂停和定位时间。
现实类比：文字逐字亮起后落色
需要保留：中文依次显现，每字先亮暖色并带光晕，随后落回正文色；英文随后按词出现。
明确排除：不改变单元身份、错峰先后或固定随机关系。
对应参考：本地目录「文字逐字亮起后落色」
源码：catalog/effects/aboutlove.js 中的 type-reveal
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：保留原设计尺寸、曲线、逐格节奏和固定随机位置。目录仅裁出所需图层并等比展示。

## 调整方式

播放速度：0.5–2 倍。

预览定位：2880 毫秒。固定演示总长：4800 毫秒。

## 示例：原有示例

动效说明：文字逐字亮起后落色
示例样式：原有示例
目的：让短文本按匀速打字节奏出现
对象：WISE MOTION 字标
动作阶段：
1. 文字从下方八像素轻轻落位。
2. 整行位置固定，WISE MOTION 按阅读顺序匀速写出。
3. 完整字标保留。
节奏：1.20 秒完成一次；1 倍速度；匀速。约零点一五秒起动，主要动作 0.6 秒，末尾静止零点四五秒。保留原动作先后、错峰间距、回弹或逐字的相对关系；速度控件整体调整。
触发与联动：打开预览后按固定顺序播放；可暂停和定位时间。
现实类比：地址栏的一行字从左到右写出
需要保留：保留原地址字体、短距落位与匀速写字；完整行宽固定，已写出的字保持。
明确排除：不加入光标闪烁，不改变字形，不随字数增加重新居中。
对应参考：本地目录「文字逐字亮起后落色」
源码：catalog/effects/attention.js 中的 type-reveal
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：提取本机减法原工程 typeAddress 的字体和动作；使用目录已打包的 Oswald，文字改为 WISE MOTION。最终原样式隐藏光标，示例同样不显示。 画面统一采用展示片时间线的近黑/暖白与少量彩色强调，白天按同一色相适配；原几何与动作关系保留。

使用同一动作定义，设置 `variant_id: "original"`；目录和相关动作弹窗均可切换。

### 可替换内容

通过组件 `content` 为当前实例赋值；字段含义与字体、宽度限制见 [组件说明](../../REMOTION.md)。默认内容如下：

```json
{
  "text": "WISE MOTION"
}
```

- text（逐字显示的文字）：最多 13 字。
