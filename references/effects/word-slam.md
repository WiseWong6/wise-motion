# 文字撞入与错位套印

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：文字撞入与错位套印
目的：按需要选择连续换词的冲击节奏、三层文字的错位印刷质感或像素文字接续。
对象：八个英文词、主词的三层错色文字或反白块、最近三个旧词残影
动作阶段：
1. 当前词硬切到由词序确定的新位置，并保留原作的字号差异和短促抖动。
2. 按半秒源节拍依次替换八个词，错色叠印与反白块按原规则切换，最多保留三个旧词残影。
3. 最后一个词及其残影停止抖动，保持完整画面。
节奏：4.20 秒完成一次；1 倍速度；匀速。原八词近四秒的连续段映射为 3.6 秒，开头停留 0.15 秒，末尾停留 0.45 秒；保持词序和等间隔换词，结束时冻结末词。
触发与联动：按固定词序演示，可播放、暂停、重播及任意拖动定位。
现实类比：像把一组字样接连压印在纸上，每次换一个位置，前几次印迹还隐约留着。
需要保留：保留八词原顺序、半秒源节拍、固定取值的位置与字号、每秒二十四格的抖动、错色叠印或反白规则，以及最多三个旧词残影；回拖能恢复相同画面。
明确排除：不要改成词语平滑滑行或旧词重新排版，不添加下落、碰撞物理或新残影，不带年代数字、背景划痕、外围标题与声音。
对应参考：本地目录「文字撞入与错位套印」
源码：catalog/effects/word-slam.js 中的 word-slam
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：从本机 Claude 动效演进史的词语段提取完整八词，保留原位置、大小层次和每格取值；字体统一为目录的 Oswald Bold，反白块按本地字体实宽适配，主字和红色错层随明暗主题切换。只保留文字对象，去掉外围年代、标题、划痕和声音；原工程只读。

## 调整方式

播放速度：0.5–2 倍。
原八词近四秒的连续段映射为 3.6 秒，开头停留 0.15 秒，末尾停留 0.45 秒；保持词序和等间隔换词，结束时冻结末词。

预览定位：2018 毫秒。固定演示总长：4200 毫秒。

### 可替换内容

通过组件 `content` 为当前实例赋值；字段含义与字体、宽度限制见 [组件说明](../../REMOTION.md)。默认内容如下：

```json
{
  "words": [
    "CUT",
    "SCRATCH",
    "BLEED",
    "LAYER",
    "DISTORT",
    "EXPOSE",
    "REPEAT",
    "OBSESS"
  ]
}
```

- words（依次撞入的词）：1–8 项，每项最多 16 字。

## 示例：像素文字放大滑入

动效说明：文字撞入与错位套印
示例样式：像素文字放大滑入
目的：七个词每2/3秒轮换；当前词从左侧滑入并放大回弹，停留后向右滑出。
对象：七组像素词与滚动横线
动作阶段：
1. 每2/3秒新词由左侧进入，放大回弹。
2. 词在中央短暂保持；八条横线持续滚动。
3. 最后2/15秒向右滑出，由下一个词接续。
节奏：4.67 秒完成一次；1 倍速度；匀速。七个词各2/3秒；前0.2秒滑入，前7/30秒回弹，末2/15秒滑出，示例共14/3秒。 基础速度1已包含原绘制的1.5倍速度。
触发与联动：按固定词序演示，可播放、暂停、重播及任意拖动定位。
现实类比：像把一组字样接连压印在纸上，每次换一个位置，前几次印迹还隐约留着。
需要保留：字号为整数像素倍率1+4×回弹曲线；位移由三次减速控制，底部下一词横向滚动。
明确排除：不添加撞击震屏、旋转、叠印或新的词序。
对应参考：本地目录「文字撞入与错位套印」
源码：catalog/effects/word-slam.js 中的 word-slam
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：保留320×180像素画板、原色与源像素格；基础速度为原绘制的1.5倍，不含声音。

使用同一动作定义，设置 `variant_id: "pixel-motion"`；目录和相关动作弹窗均可切换。

### 此示例的独立工程

- [逐帧组件](../../catalog/remotion/pixel-motion.jsx)与目录共用实际绘制函数。
- 复制源码或命令行导出包含固定依赖、绘制源码、本地素材清单与许可；字体素材随命令行导出复制。

## 示例：文字错位套印

动效说明：文字撞入与错位套印
示例样式：文字错位套印
目的：三层低透明度年份彼此错开，每秒十二次改变小幅偏移，保留印刷套版不齐的细边。
对象：三层 1995 年份大字
动作阶段：
1. 三层大字同时存在，分别保留百分之五、七、九的透明度。
2. 横向三十像素、纵向二十像素的范围内独立错位。
3. 每格更新后停住，形成清楚的低帧率套印。
节奏：3.00 秒完成一次；1 倍速度；匀速。保留原片局部时间，不套用目录统一压缩；播放速度只改变整体快慢。
触发与联动：打开后按原片局部时间播放；可暂停、重播和任意定位。
现实类比：三层低透明度年份彼此错开，每秒十二次改变小幅偏移，保留印刷套版不齐的细边。
需要保留：保留原片三层数量、透明度顺序、十二格取样、原字号、右对齐锚点和暖白墨色。
明确排除：不把轮廓换成模糊阴影，不把低透明叠印改成高对比多彩拖尾。
对应参考：本地目录「文字撞入与错位套印」
源码：catalog/effects/word-slam.js 中的 word-slam
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：依据本机 Claude 动效演进史源码重写局部；保留原图形几何、时间和颜色，纯英文数字使用目录的 Oswald Bold 字体。深浅模式均保留此原片特色画板；不含声音、字幕或其他场景动作。

使用同一动作定义，设置 `variant_id: "overprint"`；目录和相关动作弹窗均可切换。
