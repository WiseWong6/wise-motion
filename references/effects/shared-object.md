# 同一主体跨场

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：同一主体跨场
目的：让场景切换保留视觉线索
对象：无底板的纸飞机图标
动作阶段：
1. 无底板的纸飞机图标位于列表中的一个位置，图标画框保持 1:1。
2. 背景更换时，同一个图标连续移动并等比放大。
3. 图标进入新的详情位置，保持原有形状与比例。
节奏：1.80 秒完成一次；1 倍速度；末尾减速。约零点一五秒起动，主要动作 1.2 秒，末尾静止零点四五秒。保留原动作先后、错峰间距、回弹或逐字的相对关系；速度控件整体调整。
触发与联动：打开预览后按固定顺序播放；可暂停和定位时间。
现实类比：跟着同一对象走入新场景
需要保留：同一个无底板的纸飞机图标跨越两个版面，位置和尺寸连续变化。
明确排除：保持对象身份，不另造一个图标。
对应参考：本地目录「同一主体跨场」
源码：catalog/effects/transition.js 中的 shared-object
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：画布 640×360，纸飞机使用 128×128 的正方形图框，无底板、边框或阴影。图标中心从 (205,203) 移到 (320,180)，等比缩放从 0.55 增至 1；同一个图标节点贯穿两个版面。

## 调整方式

播放速度：0.5–2 倍。
速度变化：匀速、末尾减速、平缓往返。

预览定位：1007 毫秒。固定演示总长：1800 毫秒。

## 源码与使用

- [自编源码](../../catalog/effects/transition.js)，注册名称：`shared-object`。
- [统一播放接口](../runtime-interface.md)，可播放、暂停、重播、定位时间和释放资源。
- [Anime.js 官方文档](https://animejs.com/documentation/)；使用固定版本 4.5.0 的计时器与速度曲线。
- 自编效果未复制官方示例素材；许可为 Apache-2.0。第三方 Anime.js 保留 MIT 许可。

这是一个单个动作，可在组合片段中复用。
