# 同形承接

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：同形承接
目的：让场景切换保留视觉线索
对象：跨画面保持身份的同一个对象
动作阶段：
1. 卡片位于列表中的一个位置。
2. 背景更换时，卡片连续移动并放大。
3. 卡片进入新的详情位置。
节奏：1.80 秒完成一次；1 倍速度；末尾减速。约零点一五秒起动，主要动作 1.2 秒，末尾静止零点四五秒。保留原动作先后、错峰间距、回弹或逐字的相对关系；速度控件整体调整。
触发与联动：打开预览后按固定顺序播放；可暂停和定位时间。
现实类比：跟着同一对象走入新场景
需要保留：同一张卡片跨越两个版面，位置和尺寸连续变化。
明确排除：保持对象身份，不另造一张卡片。
对应参考：本地目录「同形承接」
源码：catalog/effects/transition.js 中的 shared-object
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：使用自有抽象卡片与文字演示；对象内容、尺寸和总时长可调整，动作结构不变。 画面统一采用展示片时间线的近黑/暖白与少量彩色强调，白天按同一色相适配；原几何与动作关系保留。
