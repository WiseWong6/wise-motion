# 配色同步轮换

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：配色同步轮换
目的：在保留版式与图表数据的同时展示多种主题配色。
对象：固定的主色块、色名与色值、三根高度不变的柱条、六色色条及选中标记
动作阶段：
1. 完整配色组件先呈现第一种主色，六色色条常驻。
2. 主色块和前两根柱条每隔零点二秒直接换色，色名、色值及选中标记同步切换。
3. 第六种颜色保持，第三根灰色柱条与所有几何位置全程不变。
节奏：1.80 秒完成一次；1 倍速度；匀速。开头停留 0.15 秒，六色各显示 0.20 秒，末尾再停留 0.45 秒；原作换色间隔保留，观看速度整体调整。
触发与联动：固定时间表驱动六色切换，可暂停、重播和拖动定位。
现实类比：同一张排版样张依次试穿六种配色。
需要保留：保留原六色顺序、主色块与两根柱条的同步换色、固定灰柱、六色色条及选中标记；文字更新时位置不动，颜色之间直接切换。
明确排除：不要替换图形、改变柱高、交替反转整页明暗，或将颜色做成平滑渐变；不带外围十色目录、粒子身份、整页入退场与声音。
对应参考：本地目录「配色同步轮换」
源码：catalog/effects/theme-color-cycle.js 中的 theme-color-cycle
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：核对本机减法主题正本 cta-colors.js 与 cta-colors.css 后提取原主题示例组件，保留六种真实色值、色名、柱形尺寸、色条和选中标记；整体缩为六成，字体与中性色沿用目录。仅提取连续换色段，开头直接呈现组件，末尾保留第六色；不带原整页入退场、十色目录、粒子、声音或依赖，原工程只读。

## 调整方式

播放速度：0.5–2 倍。
开头停留 0.15 秒，六色各显示 0.20 秒，末尾再停留 0.45 秒；原作换色间隔保留，观看速度整体调整。

预览定位：850 毫秒。固定演示总长：1800 毫秒。
