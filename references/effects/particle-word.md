# 粒子聚散成字

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：粒子聚散成字
目的：用一次完整的粒子聚散完成文字登场和收尾，闪光与画面质感随主动作配合。
对象：固定的 7,000 个粒子、WISE MOTION 字形目标、双环与闪光质感
动作阶段：
1. 细光带增亮后，白闪与双环伴随粒子从中心爆散。
2. 每个粒子按自己的延迟汇聚到固定字形，组成字标并短暂停留。
3. 同一批粒子依次吸入中心，最后亮点消失并停住。
节奏：4.00 秒完成一次；1 倍速度；匀速。开头细光带约零点一五秒；随后沿用原作三点五秒的爆散、聚字、吸入关系；末尾收掉中心亮点，总长四秒。速度控件整体调整。
触发与联动：打开预览后按固定时间表演示；可暂停和定位。
现实类比：一团粒子炸开后排成文字，读到字标后，再一起收回中心。
需要保留：保留同一批粒子的身份、固定方向和速度、逐点延迟、字形目标、先爆散再聚字再吸入的顺序；白闪与震屏分别衰减，辉光和固定噪点作为附加质感。
明确排除：不要重复播放原片裁剪；不把辉光、噪点、白闪或光带另列为这套动作的重复入口；不能用随机散点代替真正字形。
对应参考：本地目录「粒子聚散成字」
源码：catalog/effects/promo-particles.js 中的 particle-word
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：由本机 Claude 宣传片的末尾粒子段提炼。保留 7,000 个粒子的固定参数和原运动公式；字形替换为本包 Oswald Bold 的 WISE MOTION 预存轮廓。光带、白闪、双环、震屏、辉光、暗角和固定噪点并入一次演示。末尾亮点淡去为目录展示收尾；不依赖原视频、系统字体或声音。明暗主题沿用目录颜色。

## 调整方式

播放速度：0.5–2 倍。
开头细光带约零点一五秒；随后沿用原作三点五秒的爆散、聚字、吸入关系；末尾收掉中心亮点，总长四秒。速度控件整体调整。

预览定位：2450 毫秒。固定演示总长：4000 毫秒。

### 可替换内容

通过组件 `content` 为当前实例赋值；字段含义与字体、宽度限制见 [组件说明](../../REMOTION.md)。默认内容如下：

```json
{
  "text": "WISE MOTION"
}
```

- text（单行粒子文字）：最多 64 字。
