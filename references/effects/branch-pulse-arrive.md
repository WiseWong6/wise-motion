# 分路抵达

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：分路抵达
目的：独立复用依次向三个目标发送并显示抵达反馈的过程。
对象：三组光团亮芯与光晕、三个端点扩散辉光
动作阶段：
1. 首个光团从圆周发出，其后两路各晚 1.1 秒。
2. 每个光团沿原二次曲线向端点前进，单程持续 0.9 秒。
3. 光团到达即消失，原端点辉光扩大并在 0.55 秒内淡去。
节奏：4.30 秒完成一次；1 倍速度；匀速。独立演示 4.3 秒；首束约 0.15 秒发出、1.05 秒抵达，后两束保留原 1.1 秒间隔。
触发与联动：打开后独立播放；可暂停、重播和任意定位。
现实类比：依次寄出三束光，每束光到达自己的接收位置后亮一下。
需要保留：保留三条原二次曲线、双重三次缓动、0.9 秒单程、1.1 秒错峰和端点 16 到 40 的光晕半径变化。
明确排除：不改为多路向同一点汇入，不沿直线发射，不提前显出端点光晕，不重复反向往返。
对应参考：本地目录「分路抵达」
源码：catalog/effects/radial-branch-flow.js 中的 branch-pulse-arrive
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：直接抽取组合发射与抵达层；只去掉前 1.7 秒等待，共用原路径、明暗包络和暖色光效。独立不建立枝干、圆心和卡片。
