# 弧线汇字

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：弧线汇字
目的：提取原片中字符沿弧汇入中心的具体主体、造型与时间关系，独立复用并能与原组合逐层对照。
对象：原提示词的 110 个字符、各自弧线与共同中心
动作阶段：
1. 从原场景5秒的完整提示词位置开始。
2. 5.3秒起字符按0.007秒错峰沿各自弧线绕出，旋转放大并转成七种年代色。
3. 字符接近中心时缩小和淡去，最后一个字在原场景约7.55秒消失。
节奏：3.00 秒完成一次；1 倍速度；匀速。独立 3 秒，对应原片 51–54 秒，保持原速。
触发与联动：打开后播放；可暂停、重播和任意定位。
现实类比：字从原三行提示词的位置逐个飞出，先向外绕行、旋转放大，再缩进同一个中心。
需要保留：每字独立而固定的推离距离、弧线控制点、旋转方向、先大后小曲线，原中心 960×540 与七种年代配色。
明确排除：不做向外爆炸后停住，不改成直线吸入，不替换成随机粒子。
对应参考：本地目录「弧线汇字」
源码：catalog/effects/reel-prompt-outro.js 中的 prompt-char-gather
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
