# 文字绕弧汇聚

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：文字绕弧汇聚
目的：提取原片中字符沿弧汇入中心的具体主体、造型与时间关系，独立复用并能与原组合逐层对照。
对象：原提示词的 110 个字符、各自弧线与共同中心
动作阶段：
1. 从原场景5秒的完整提示词位置开始。
2. 5.3秒起字符按0.007秒错峰沿各自弧线绕出，旋转放大并转成七种年代色。
3. 字符接近中心时缩小和淡去，最后一个字在原场景约7.55秒消失。
节奏：3.00 秒完成一次；1 倍速度；匀速。独立 3 秒，对应原片 51–54 秒，保持原速。
触发与联动：打开后播放；可暂停、重播和任意定位。
现实类比：字从原三行提示词的位置逐个飞出，先向外绕行、旋转放大，再缩进同一个中心。
需要保留：每字独立而固定的推离距离、弧线控制点、旋转方向、先大后小曲线，原中心 960×540 与七种年代配色。
明确排除：不做向外爆炸后停住，不改成直线吸入，不替换成随机粒子。
对应参考：本地目录「文字绕弧汇聚」
源码：catalog/effects/reel-prompt-outro.js 中的 prompt-char-gather
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：仅创建原110字与原光标，从组合局部5–8秒原速裁切；共用原逐字路径和绘制函数，不提前隐藏尚未飞出的字。保留原深色背景与中文正文Light字体。

## 调整方式

播放速度：0.5–2 倍。
独立 3 秒，对应原片 51–54 秒，保持原速。

预览定位：1000 毫秒。固定演示总长：3000 毫秒。

## 示例：词句沿弧汇入行首光标

动效说明：文字绕弧汇聚
示例样式：词句沿弧汇入行首光标
目的：友字中的词句从各自原位置沿弧汇入下一行的行首点，点随后成为光标。
对象：词句沿弧汇入行首光标
动作阶段：
1. 建立对象与空间关系。
2. 友字中的词句从各自原位置沿弧汇入下一行的行首点，点随后成为光标。
3. 保留该阶段的落定或离场结果。
节奏：2.30 秒完成一次；1 倍速度；匀速。本示例2.3秒；帧号直接换算局部时间，支持倒放定位和重播。
触发与联动：打开后播放；可暂停、重播和任意定位。
现实类比：词句沿弧汇入行首光标
需要保留：友字中的词句从各自原位置沿弧汇入下一行的行首点，点随后成为光标。
明确排除：不改变单元身份、错峰先后或固定随机关系。
对应参考：本地目录「文字绕弧汇聚」
源码：catalog/effects/aboutlove.js 中的 prompt-char-gather
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：保留原设计尺寸、曲线、逐格节奏和固定随机位置。目录仅裁出所需图层并等比展示。

使用同一动作定义，设置 `variant_id: "aboutlove-34"`；目录和相关动作弹窗均可切换。
