# 透视网格前行

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：透视网格前行
目的：独立复用原片透视地面的向前流动，保持消失点和纵深关系。
对象：紫黑地面、固定纵线、连续滚来的横线与水平亮边
动作阶段：
1. 纵线固定汇向地平线，远处横线密集。
2. 横线由远向近滚来，间距随靠近自然拉开。
3. 近处横线移出画面，远处接续补入，网格亮度随节拍起伏。
节奏：6.00 秒完成一次；1 倍速度；匀速。保留原片六秒时间，太阳上升用前 1.3 秒，其余运动持续至段尾；播放倍率只改变观看速度。
触发与联动：打开后播放；可暂停、重播和任意定位。
现实类比：沿着透视方格地面向前行进，近处格线更快越过视野。
需要保留：横线坐标按纵深倒数计算，固定纵线不旋转；保留 7 像素柔边与 2 像素亮芯、原品红配色和半秒亮度脉冲。
明确排除：不把地面当作平面图案匀速上移，不改变固定消失点，不误把亮度起伏实现成线宽变化。
对应参考：本地目录「透视网格前行」
源码：catalog/effects/reel-neon.js 中的 perspective-grid-flow
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：按本机 Claude 动效演进史原片 10–16 秒及 sNeon 源码重写；深浅模式均保留原霓虹色，独立动作与组合共用原位置、大小和计时。省去文字、转场和声音。

## 调整方式

播放速度：0.5–2 倍。
保留原片六秒时间，太阳上升用前 1.3 秒，其余运动持续至段尾；播放倍率只改变观看速度。

预览定位：2600 毫秒。固定演示总长：6000 毫秒。
