# 中心汇聚散射成字

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：中心汇聚散射成字
目的：六颗金属球从高低、前后错落的散开位置沿弧线直接汇向中心，短促压聚后向四周散射粒子，再回收汇聚为圆润立体字母。
对象：高低与前后错落的六颗金属球、753颗六色金属粒子与由它们汇聚而成的MOTION六个字母
动作阶段：
1. 从六球散得最开的姿态开始，用0.76秒沿不同弧线直接汇向中心（0,0.33,0），中途没有水平队列、停顿或第二次冲撞；到达后在中心压住0.05秒。
2. 0.81–1.16秒：753颗六色金属粒子从半径0.305的同一中心向四周散射，每种颜色分布在四个方向；约四分之三冲出画面，少量留在画面内延续动势，散开时粒径最多放大65%。
3. 1.16–2.26秒：同一批粒子沿弧线回收至字面；2.04–2.42秒字形实体逐渐填满，颗粒在收拢末段退去，两个O保持圆形中空；定格至2.96秒。
节奏：2.96 秒完成一次；1 倍速度；匀速。总长2.96秒；0.76秒汇到中心、0.81秒开始散射、1.16秒达到最远、2.26秒粒子抵达字面，2.42秒形成完整实体字面，余下保持。
触发与联动：打开后按固定时间播放，可暂停、重播、定位与调整整体速度。
现实类比：散开的六颗金属球各自沿弧线被吸向同一个中心，释放为四散珠粒，再收拢拼成六个金属字母。
需要保留：从散开姿态直接连续汇聚、0.76秒空间弧线、0.05秒中心压聚、每种颜色都从中心向四周散射、同一批粒子冲出画面再回收、粒子投影与字面对齐、收拢末段直接形成实体字面、两个正圆O，汇聚结束无残留散点。
明确排除：不播放前置落地，不先排成水平队列，不插入停顿与二次冲撞，不让球体汇到中心后反弹，不按左右分组反射粒子，不用尖锐碎屑或白色火花替代金属粒子，不增加落位后的停留或整字透明叠加，不加尾句或扫光。
对应参考：本地目录「中心汇聚散射成字」
源码：catalog/effects/metal-impact.js 中的 horizontal-metal-type
来源与许可：原码提取与接入，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：使用确定性的设计轨迹与自编曲面字形；示例文字固定为 MOTION，两个 O 为同心圆环。

## 调整方式

总长2.96秒；0.76秒汇到中心、0.81秒开始散射、1.16秒达到最远、2.26秒粒子抵达字面，2.42秒形成完整实体字面，余下保持。
