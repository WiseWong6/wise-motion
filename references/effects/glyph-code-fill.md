# 字形内文字流动

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：字形内文字流动
目的：用字形内部持续流动的源码表达文字由代码构成，同时保持大字可辨认。
对象：“代码”二字的固定轮廓、笔画内滚动的源码行与外描边
动作阶段：
1. 大字轮廓从开始就完整显示，源码材料仅出现在笔画内部。
2. 源码行向左滚动，奇偶行速度不同，同时缓慢上移；行内容按固定节拍轮换。
3. 移出上方的行在画板下方补入，连续播放时轮廓和外描边始终固定。
节奏：4.00 秒一个周期，持续循环；1 倍速度；匀速。保留原作内部材料的速度与换行节拍，四秒为目录播放窗口；跨轮次按累计时间继续滚动，可整体调节速度。
触发与联动：打开预览后持续滚动；可暂停、重播及任意拖动定位。
现实类比：大字的笔画像窗口，背后的代码带持续滚动，只透出窗口里面的部分。
需要保留：保留“代码”字形的固定裁剪窗口、16 行原源码材料、奇偶行横向速度差、向上滚动和每五行的强调色；填充与外描边引用同一字形。
明确排除：不将内部材料替换为粒子汇聚成字，不让源码露出笔画，不添加打字光标、相邻口号或整字反复缩放。
对应参考：本地目录「字形内文字流动」
源码：catalog/effects/glyph-code-fill.js 中的 glyph-code-fill
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：从本机 Claude 宣传片 scene3 的代码段独立提炼。历史预览登记为 10.4–11.1 秒，源码中实际字形段为 10.5–11.0 秒。保留内部滚动公式、原代码、字形比例与描边；去掉相邻口号、背景横扫和整字冲击，扩展为连续滚动。中文轮廓采用目录本地粗体，源码采用本地 Oswald 并保留原等宽行宽；明暗主题共用颜色变量。原工程保持只读。
