# 沿曲线移动

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：沿曲线移动
目的：两个亮点沿同一心形反向加速运行，短尾迹逐渐衰减，已经跑过的圈留下放大淡去的轮廓。
对象：双光点反向绕轮廓加速
动作阶段：
1. 建立对象与空间关系。
2. 两个亮点沿同一心形反向加速运行，短尾迹逐渐衰减，已经跑过的圈留下放大淡去的轮廓。
3. 保留该阶段的落定或离场结果。
节奏：7.74 秒完成一次；1 倍速度；匀速。本示例7.74秒；帧号直接换算局部时间，支持倒放定位和重播。
触发与联动：打开预览后按固定顺序播放；可暂停和定位时间。
现实类比：双光点反向绕轮廓加速
需要保留：两个亮点沿同一心形反向加速运行，短尾迹逐渐衰减，已经跑过的圈留下放大淡去的轮廓。
明确排除：不改变单元身份、错峰先后或固定随机关系。
对应参考：本地目录「沿曲线移动」
源码：catalog/effects/aboutlove.js 中的 curve-path
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：保留原设计尺寸、曲线、逐格节奏和固定随机位置。目录仅裁出所需图层并等比展示。

## 调整方式

播放速度：0.5–2 倍。
速度变化：匀速、末尾减速、平缓往返。

预览定位：4644 毫秒。固定演示总长：7740 毫秒。

- 提取自有场景的绘制函数、固定随机关系、字形和时间编排；目录与逐帧组件共用同一实现。许可为 Apache-2.0。Remotion、React与所用素材遵循各自许可，见来源说明。

## 示例：文档沿曲线递送

动效说明：沿曲线移动
示例样式：文档沿曲线递送
目的：两份文档沿二次曲线从保留结果进入模型框。
对象：文档沿曲线递送
动作阶段：
1. 按固定帧定位原始起点。
2. 两份文档沿二次曲线从保留结果进入模型框。
3. 保留原动作末帧，重播回到同一起点。
节奏：1.67 秒完成一次；1 倍速度；匀速。按30帧时钟播放，共50帧。
触发与联动：按固定时间顺序播放，可暂停、重播和任意定位。
现实类比：双光点反向绕轮廓加速
需要保留：截取原194–243帧。两条二次曲线从(400,72+168i)，控制点(450,72+168i)，到(480,328+112i)；文档20×26，透明度sin(进度×π)，第二份错后0.025归一进度。
明确排除：不打断对象连续变化，不改变原几何和帧节奏。
对应参考：本地目录「沿曲线移动」
源码：catalog/effects/deepseek-review.js 中的 deepseek-result-delivery
