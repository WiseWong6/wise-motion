# 三联主体错峰升入

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：三联主体错峰升入
目的：三个完整主体以固定错峰从下方升入，分别倾斜落位组成三联画。
对象：三张透明产品静帧和固定标题
动作阶段：
1. 暖白底与银色曲面背景，三个完整主体在画面下方等待。
2. 三个主体分别在第0、4、8帧开始从下方上移，带不同固定倾角。
3. 主体在第20、24、28帧落位，三联构图与细微持续转角保持。
节奏：2.00 秒完成一次；1 倍速度；匀速。按24帧/秒，以当前帧计算固定演示时钟。
触发与联动：打开预览按固定时间线播放；可以暂停、定位和重播。
现实类比：三个完整主体以固定错峰从下方升入，分别倾斜落位组成三联画。
需要保留：透明静帧的完整轮廓、原长宽比、错峰位移和各自倾角。
明确排除：不要整体移动三张图片，不拉伸或裁切主体，不用淡入代替上移。
对应参考：本地目录「三联主体错峰升入」
源码：catalog/effects/time-in-motion.js 中的 fan-object-rise
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：怀表为动作示例，可替换主体；物理钟表状态仅为视觉演示。

## 调整方式

播放速度：0.5–2 倍。
按24帧/秒，以当前帧计算固定演示时钟。

预览定位：1250 毫秒。固定演示总长：2000 毫秒。
