# 分枝生长

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：分枝生长
目的：独立复用由中心向三个方向展开、随后确认完成的路径生长。
对象：三条二次曲线枝干与三个枝尖亮点
动作阶段：
1. 从原圆周三个起点出发，三路生长相隔 0.25 秒。
2. 每条曲线用 0.65 秒长到端点，亮点始终位于当前枝尖。
3. 按原抵达时刻逐路改为青色实线，三条完整路径最终保留。
节奏：5.35 秒完成一次；1 倍速度；匀速。独立演示 5.35 秒；从 0.15 秒开始生长，0.25 秒错峰，原抵达后的虚实转换也完整保留。
触发与联动：打开后独立播放；可暂停、重播和任意定位。
现实类比：从一个中心依次伸出三条路，每条路完成传递后变成稳定实线。
需要保留：保留原三条二次曲线、圆周起点、双重三次缓动、虚线滚动、枝尖和三次凝实时间。
明确排除：不改为单条心电描线或竖直植物展叶，不改端点和弯曲方向，不在长成前显示完整路径。
对应参考：本地目录「分枝生长」
源码：catalog/effects/radial-branch-flow.js 中的 radial-branch-grow
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：直接抽取组合枝干层，与组合共用路径截取和绘制；独立时钟仅去掉前 0.65 秒等待，全部几何和原目录配色不变。
