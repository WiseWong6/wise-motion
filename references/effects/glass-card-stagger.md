# 透光卡片错层

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：透光卡片错层
目的：语音、对话和控制卡错层移动，卡面模糊透入后方画面，并以局部光照显示厚度。
对象：Voice input 语音卡、WISE 创作对话卡与 Create／Light 控制卡
动作阶段：
1. 三张卡保持不同的前后顺序，从画面近处和左下方移入。
2. 卡片缩远后再次拉近；回复逐行出现，开关开启，滑杆从30%升至74%。
3. 卡片回到完整可见的错层构图并短暂停留。
节奏：3.00 秒完成一次；1 倍速度；匀速。开始等待0.15秒，完成后静止0.45秒，中间保持各对象的先后关系。
触发与联动：打开后按固定时间演示，可暂停、重播及任意定位。
现实类比：语音、对话和控制卡错层移动，卡面模糊透入后方画面，并以局部光照显示厚度。
需要保留：后方语音卡300×148、中间对话卡578×414、前景控制卡356×202；每张卡采样当前后方画面并作10像素模糊，保留左暗右蓝与固定移动轨迹。
明确排除：不用不透明色块代替透光，不让三张卡共用同一移动轨迹。
对应参考：本地目录「透光卡片错层」
源码：catalog/effects/glass-light.js 中的 glass-card-stagger
来源与许可：原码提取与接入，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：保留紫蓝光场、透光材质与柔光气泡；界面采用 WISE 创作主题文案，字标改为 WISE MOTION，未携带原片媒体。

## 调整方式

播放速度：0.5–2 倍。
开始等待0.15秒，完成后静止0.45秒，中间保持各对象的先后关系。

预览定位：2500 毫秒。固定演示总长：3000 毫秒。
