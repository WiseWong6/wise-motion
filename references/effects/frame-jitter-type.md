# 文字逐格错位

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：文字逐格错位
目的：同一组大字按每秒二十四格轻微错位，偶尔整组向下跳一格，三行文字依次出现。
对象：三行 THE / NERVOUS / TYPE. 大字
动作阶段：
1. 三行分别在零、零点二五和零点五秒出现。
2. 整组按帧号产生横向与纵向偏移，每行还保留独立的小幅横向偏移。
3. 同一帧保持稳定，少数帧整组下跳三十六像素。
节奏：1.90 秒完成一次；1 倍速度；匀速。保留原片局部时间，不套用目录统一压缩；播放速度只改变整体快慢。
触发与联动：打开后按原片局部时间播放；可暂停、重播和任意定位。
现实类比：同一组大字按每秒二十四格轻微错位，偶尔整组向下跳一格，三行文字依次出现。
需要保留：保留原片全局二十点一秒至二十二秒的三行文字、每秒二十四格取样、整帧与逐行两层位移、黑底暖白与红色末行。
明确排除：不重新引入已删除的手绘下划线，不用每次播放都变化的随机数。
对应参考：本地目录「文字逐格错位」
源码：catalog/effects/reel-grit-key.js 中的 frame-jitter-type
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：依据本机 Claude 动效演进史源码重写局部；保留原图形几何、时间和颜色，纯英文数字使用目录的 Oswald Bold 字体。深浅模式均保留此原片特色画板；不含声音、字幕或其他场景动作。

## 调整方式

播放速度：0.5–2 倍。
保留原片局部时间，不套用目录统一压缩；播放速度只改变整体快慢。

预览定位：700 毫秒。固定演示总长：1900 毫秒。

- [Anime.js 官方文档](https://animejs.com/documentation/)；使用固定版本 4.5.0 的计时器与速度曲线。
- 自编效果未复制官方示例素材；许可为 Apache-2.0。第三方 Anime.js 保留 MIT 许可。
