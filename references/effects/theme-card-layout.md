# 排版逐行展开

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：排版逐行展开
目的：在一张卡片内逐步建立眉题、两行标题与说明的排版层次。
对象：原黑色圆角卡片、眉题条、两条标题块、说明条、绿色强调线、确认光标和卡面微光
动作阶段：
1. 黑色主题卡从下方轻微上移并淡入。
2. 眉题条、两条标题块和说明条按相同间距依次从左侧滑入，宽度同步展开；卡面微光持续横扫。
3. 绿色强调线划出，确认光标闪烁；排版完成后整张卡片稳定停留。
节奏：3.00 秒完成一次；1 倍速度；匀速。约零点一五秒起动，主要动作 2.4 秒，末尾静止零点四五秒。保留原动作先后、错峰间距、回弹或逐字的相对关系；速度控件整体调整。
触发与联动：打开预览后由卡片进入开始，依次建立四行内容；可暂停、重播和拖动时间。
现实类比：一张黑色主题卡逐行完成自己的标题和说明排版。
需要保留：保留原黑色卡面、细灰边框、圆角、四行排版块的宽高与位置，绿色眉题和强调线、浅色标题块及灰色说明条。卡片轻微上移淡入，行间错峰半秒，滑入时同步展开；原光标和独立固定卡面扫光保留。
明确排除：不重画成白色卡片，不改原配色和比例，不把原排版块替换成新增文案，不加入外围标题、字幕、背景或后续场景。
对应参考：本地目录「排版逐行展开」
源码：catalog/effects/history-patterns.js 中的 theme-card-layout
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：核对教程制作四步场景中主题卡的原绘制代码与主题色后独立重写。卡面、四行块、强调线、光标、扫光及其裁剪保留原界面，等比缩为六成并居中；外部沿用目录统一画板和底色。原源码只读，不复制影片、字体或声音。 画面统一采用展示片时间线的近黑/暖白与少量彩色强调，白天按同一色相适配；原几何与动作关系保留。

## 调整方式

播放速度：0.5–2 倍。
约零点一五秒起动，主要动作 2.4 秒，末尾静止零点四五秒。保留原动作先后、错峰间距、回弹或逐字的相对关系；速度控件整体调整。

预览定位：2775 毫秒。固定演示总长：3000 毫秒。
