# 中心词连接周围词语

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：中心词连接周围词语
目的：适合表达一个词与周边语境的关系；仅保留下方关系图。
对象：中心词、六个周围词、边缘相接的连线
动作阶段：
1. 中心词弹出。
2. 周围六个词错峰出现。
3. 连线依次长出，端点闪光后停留。
节奏：2.92 秒完成一次；1 倍速度；匀速。默认沿用成片1.3倍节奏，约2.92秒。
触发与联动：打开后按固定时间播放，可暂停、重播与任意定位。
现实类比：中心的猫标签先弹出，周围词语依次出现，连接线从边缘伸到各词语边缘。
需要保留：连线在标签边缘结束，不穿过字；不带上方人物档案卡。
明确排除：不添加未选片段，不改原几何和材质，不以整体淡入替代内部动作。
对应参考：本地目录「中心词连接周围词语」；所用动作：线条逐段画出、依次入场
源码：catalog/effects/knowledge-video.js 中的 cat-context-links
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：内容和数据为原工程的固定讲解示例。适合表达一个词与周边语境的关系；仅保留下方关系图。
