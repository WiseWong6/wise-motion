# 七色色带错峰伸展

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：七色色带错峰伸展
目的：提取原片中七色色带错峰伸展的具体主体、造型与时间关系，独立复用并能与原组合逐层对照。
对象：原 CLAUDE 字形、七段年代配色细带与原落款
动作阶段：
1. 原标题与落款以完成态作为位置参照。
2. 各段从自身左端开始延展，每段比前段晚 0.06 秒。
3. 所有色段填满各自槽位，组成连续的七色色带。
节奏：1.40 秒完成一次；1 倍速度；匀速。独立 1.4 秒，色带从 0.1 秒起逐段展开。
触发与联动：打开后播放；可暂停、重播和任意定位。
现实类比：标题下方七段相邻色带分别从自身左端伸展，错峰拼成完整一条。
需要保留：原标题等宽色带、七段等分、8 像素带高、0.06 秒间隔与每段 0.6 秒伸展。
明确排除：不改变标题长度，不让色段互相挤压，也不改成整条擦除。
对应参考：本地目录「七色色带错峰伸展」
源码：catalog/effects/reel-prompt-outro.js 中的 color-segment-stagger
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：原字体轮廓与原配色保留；独立项的标题为静态参照，仅色带按原局部 3.2–4.6 秒计时。 深浅模式均保留该段原深色画面。 普通英文与数字按目录规范使用 Oswald Bold，中文及混排正文用 Light；原逐字落点与换行保持，片尾 CLAUDE 主字是造型轮廓例外。
