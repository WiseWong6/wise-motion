# 心电轨迹突然失真再恢复

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：心电轨迹突然失真再恢复
目的：连续前进的心电轨迹在指定时刻突然出现高频噪声，噪声幅度迅速衰减；失真段留在历史尾迹里，随时间滚走。
对象：心电轨迹突然失真再恢复
动作阶段：
1. 建立对象与空间关系。
2. 连续前进的心电轨迹在指定时刻突然出现高频噪声，噪声幅度迅速衰减；失真段留在历史尾迹里，随时间滚走。
3. 保留该阶段的落定或离场结果。
节奏：2.75 秒完成一次；1 倍速度；匀速。本示例2.75秒；帧号直接换算局部时间，支持倒放定位和重播。
触发与联动：打开预览后按固定时间表演示；可暂停和定位。
现实类比：心电轨迹突然失真再恢复
需要保留：连续前进的心电轨迹在指定时刻突然出现高频噪声，噪声幅度迅速衰减；失真段留在历史尾迹里，随时间滚走。
明确排除：不改变单元身份、错峰先后或固定随机关系。
对应参考：本地目录「心电轨迹突然失真再恢复」
源码：catalog/effects/aboutlove.js 中的 heartbeat-follow
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：保留原设计尺寸、曲线、逐格节奏和固定随机位置。目录仅裁出所需图层并等比展示。

## 调整方式

播放速度：0.5–2 倍。

## 示例：原有示例

动效说明：心电轨迹突然失真再恢复
示例样式：原有示例
目的：心电折线始终完整可见，光点按线长匀速前进。
对象：一条心电折线与一个光点
动作阶段：
1. 完整心电折线常驻，光点位于起点。
2. 光点沿折线匀速走过每个转折，底线不改变。
3. 光点到达末端后回到起点，开始下一轮。
节奏：3.00 秒一个周期，持续循环；1 倍速度；匀速。一轮 3 秒；连续运动不在周期末停顿，首轮入场与累计时间同步。速度控件在此基础上整体调整。
触发与联动：打开预览后按固定时间表演示；可暂停和定位。
现实类比：心电监视器的线条运动
需要保留：心电折线始终完整可见，光点按线长匀速前进。
明确排除：不要让底线随光点出现或消失，不要沿横坐标匀速造成斜线段速度突变。
对应参考：本地目录「心电轨迹突然失真再恢复」
源码：catalog/effects/history-patterns.js 中的 heartbeat-follow
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：用用户给出的六点折线比例演示；使用现有本地动画运行方式，不引入 React 或 Framer Motion。 画面统一采用展示片时间线的近黑/暖白与少量彩色强调，白天按同一色相适配；原几何与动作关系保留。

使用同一动作定义，设置 `variant_id: "original"`；目录和相关动作弹窗均可切换。
