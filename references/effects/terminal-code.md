# 代码逐行输入

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：代码逐行输入
目的：将代码按行、按字写出，让观众看清输入过程并保留完整代码。
对象：带三色窗口按钮的终端、三行代码、方块光标与底部状态光带
动作阶段：
1. 终端窗口上移一小段并淡入。
2. 三行代码按相同间距开始逐字输入，未完成行的方块光标闪烁，底部光带横向扫描。
3. 全部代码保留，光标消失，窗口和底部光带在末尾静止。
节奏：3.00 秒完成一次；1 倍速度；匀速。约零点一五秒起动，主要动作 2.4 秒，末尾静止零点四五秒。保留原动作先后、错峰间距、回弹或逐字的相对关系；速度控件整体调整。
触发与联动：打开预览后，终端进入并逐行输入代码；支持暂停、重播与拖动。
现实类比：终端里写下想法和动效，再敲出创建语句。
需要保留：保留原石墨灰窗体、标题栏、红黄绿圆点、三行原代码及语法配色。按原半秒行间隔、每秒五十字输入，保留方块光标和底部状态光带；中文正文细体，英文沿用原紧凑字形。
明确排除：不带原场景标题、旁白和影片背景，不替换已有的命令与日志终端，不将行间错峰改成整行闪现，不在文字增加时重新居中。
对应参考：本地目录「代码逐行输入」
源码：catalog/effects/history-patterns.js 中的 terminal-code
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：核对原教程开场中的单窗终端、文字规则与主题色后独立重写。窗体等比缩为六成并居中，外部使用目录底色。保留原窗口比例、文案与配色；中文使用目录细体，英文和数字使用目录已打包的原字形。固定示例字距从原字体计算，不在播放时反复测量。 画面统一采用展示片时间线的近黑/暖白与少量彩色强调，白天按同一色相适配；原几何与动作关系保留。

## 调整方式

播放速度：0.5–2 倍。
约零点一五秒起动，主要动作 2.4 秒，末尾静止零点四五秒。保留原动作先后、错峰间距、回弹或逐字的相对关系；速度控件整体调整。

预览定位：2775 毫秒。固定演示总长：3000 毫秒。

## 示例：命令与日志

动效说明：代码逐行输入
示例样式：命令与日志
目的：复用原终端的命令输入与输出节奏，保留原窗口样式。
对象：终端窗口与九行输出
动作阶段：
1. 固定终端窗口内，命令随光标逐字输入。
2. 日志逐行输出，调试省略号随原节拍变化。
3. 通过状态显现，完整终端内容停住。
节奏：3.00 秒完成一次；1 倍速度；匀速。三秒内完成命令输入与日志输出，末尾留清晰停留；速度只改变整体快慢。
触发与联动：打开预览后按固定时间表演示；可暂停、重播与定位。
现实类比：终端窗口保持固定，命令随光标逐字输入，日志和调试状态按原顺序出现，完成后停住。
需要保留：保留原终端窗口样式、逐字命令输入、日志顺序、调试省略号和方块光标；窗口位置、比例及清晰度固定。
明确排除：不带窗口入场、缩小后退、变淡、柔焦或前景标题，去掉原场景背景与文稿。
对应参考：本地目录「代码逐行输入」
源码：catalog/effects/kimi-illustrations.js 中的 terminal-window-illustration
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：复用 Kimi 中文正本的原窗口、命令与日志，仅保留打字输出片段；窗口自始至终固定，使用目录统一画板和底色。

使用同一动作定义，设置 `variant_id: "command-log"`；目录和相关动作弹窗均可切换。

### 可替换内容

  "lines": [
    "$ kimi --model k3",

    "▸ 扫描 20+ 篇论文 … ok",
    "▸ 实现数值管线",

- lines（九行命令与日志（保留原顺序和时钟））：9–9 项，每项最多 40 字。
