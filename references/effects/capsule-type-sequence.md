# 字母落定与碰撞炸出

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：字母落定与碰撞炸出
目的：饱满彩色字母先落入胶囊地面，银球撞入后掀起胶囊，并炸出第二行字母。
对象：WISE与MOTION两行实体字母、5760根近景胶囊和远景胶囊、银色球、共享灯光与连贯镜头
动作阶段：
1. 0–1.55秒：WISE四字在0.34、0.51、0.68、0.85秒错峰落地，压缩回弹，脚下胶囊压陷并向外传出波纹。
2. 1.42秒银球飞入，1.88秒撞击前方地面；胶囊翻转飞散，奶黄地面沿距离先后微微提亮；MOTION从约1.92秒开始自右向左炸起。
3. 六个字母向外翻转，再回弹转正并排成前方第二行；胶囊约3.65秒全部归位，最后保持两行品牌画面至5秒。
节奏：5.00 秒完成一次；1 倍速度；匀速。保留5秒快节奏，1.88秒碰撞，3.65秒后完整展示；播放速度整体缩放。
触发与联动：打开后按固定时间播放；支持暂停、重播、时间定位与整体倍速。
现实类比：先让第一行落在柔软地面上，再用一次撞击炸出第二行。
需要保留：5秒完整时钟、三色光亮字母、胶囊地面、共享投影、轻微虚实、银球撞击和双行收尾；所有散开的胶囊回到自己的原位。
明确排除：不改成视频或平面贴图播放，不把整段裁剪当独立动作，不添加声音，不把设计轨迹描述为通用软体物理模拟。
对应参考：本地目录「字母落定与碰撞炸出」；所用动作：立体字母错峰落定、碰撞掀起胶囊、立体字母炸出归位
源码：catalog/effects/capsule-type.js 中的 capsule-type-sequence
来源与许可：原码提取与接入，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：字形是自编三维曲面，例字固定为WISE和MOTION；运动为确定性的设计轨迹，颜色按线性空间计算。

## 调整方式

播放速度：0.5–2 倍。
保留5秒快节奏，1.88秒碰撞，3.65秒后完整展示；播放速度整体缩放。

预览定位：4400 毫秒。固定演示总长：5000 毫秒。
