# 小猫加工机器

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：小猫加工机器
目的：原咖啡机、料斗、压力表、传送带和蒸汽管一起保留。
对象：小猫加工机器的原造型及相关运动主体
动作阶段：
1. 机器以原造型出现。
2. 料斗、压力表和传送带按原加工时序联动。
3. 保持原机器完整轮廓。
节奏：8.00 秒完成一次；1 倍速度；匀速。保留原作第0秒起的8秒；速度控件统一缩放时间。
触发与联动：打开后按原时间播放；可暂停、重播与定位。
现实类比：原咖啡机、料斗、压力表、传送带和蒸汽管一起保留。
需要保留：保留原轮廓、比例、材质、固定数据及时间关系；原咖啡机、料斗、压力表、传送带和蒸汽管一起保留。
明确排除：不改变原画法，不重排接触位置，不添加独立播放时钟、音频或外部工程依赖。
对应参考：本地目录「小猫加工机器」；所用动作：粒子落入汇集
源码：catalog/effects/scene-factory.js 中的 factory-machine-illustration
来源与许可：原码提取与接入，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：使用迁入的原作绘制，原尺寸等比适配目录；保留原色。插画只调用对应主体的实际绘制函数，组合保留前后关系。

## 调整方式

播放速度：0.5–2 倍。
保留原作第0秒起的8秒；速度控件统一缩放时间。

预览定位：4400 毫秒。固定演示总长：8000 毫秒。
