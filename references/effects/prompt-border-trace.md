# 边框逐段描绘

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：边框逐段描绘
目的：提取原片中输入框边缘循线显现的具体主体、造型与时间关系，独立复用并能与原组合逐层对照。
对象：原圆角输入边框
动作阶段：
1. 圆角边框沿原输入界面的落位路径进入，从原路径起点开始描绘。
2. 前0.8秒用先慢后快再慢的节奏完成一圈。
3. 边框保持闭合，亮度轻微起伏。
节奏：1.40 秒完成一次；1 倍速度；匀速。独立演示 1.4 秒，原场景局部 0–1.4 秒。
触发与联动：打开后播放；可暂停、重播和任意定位。
现实类比：原圆角输入框沿边缘描出，描线完成后仍有轻微亮度起伏。
需要保留：940×198 输入区域、22 像素圆角、1.4 像素描线、2276 像素原线段周期及 0–0.8 秒描绘曲线。
明确排除：不把细描线替换成外围粗发光框，不创建无关菜单、提示词或按钮。
对应参考：本地目录「边框逐段描绘」
源码：catalog/effects/reel-prompt-outro.js 中的 prompt-border-trace
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：仅创建原边框图层，保留组合中的落位、描绘与亮度变化；与组合共用同一原圆角路径和绘制函数，深浅模式均保留原深色画面。
