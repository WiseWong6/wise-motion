# 环圈分层展开

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：环圈分层展开
目的：五层圆弧依次展开，刻度沿周长建立，短弧分别转动。
对象：五层同心圆弧、120根刻度、12组角度读数
动作阶段：
1. 圆弧从顶部沿周长展开。
2. 长短刻度随展开进度出现。
3. 短弧按不同方向缓慢转动。
节奏：1.80 秒完成一次；1 倍速度；匀速。总长1.8秒，等待0.15秒后开始，末尾静止0.45秒；按统一时间计算每次画面。
触发与联动：打开后按固定时间演示，可暂停、重播及任意定位。
现实类比：五层圆弧依次展开，刻度沿周长建立，短弧分别转动。
需要保留：原版整体构图与数据保留；初始采用明亮银白#e5ebf2，扩大纯白高光面积、提高主环圈不透明度，保留金属反光与柔光，锁定切为红色#ff434d，背景为中性近黑#060709。圆弧半径190至226、间隔9；120根刻度，每10根加长；环形主体居中，在独立画板中等比放大。
明确排除：不混入其它仪表，不拉伸低分辨率画面，不用实时随机数；保持可暂停、回拖和重播。
对应参考：本地目录「环圈分层展开」
源码：catalog/effects/hud-targeting.js 中的 hud-ring-build
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：中文仪表组件以代码绘制；斜距使用原片可读帧采样，其余遥测、波形、频谱和字符为固定演示数据。独立示例放大自身内容，按实际显示像素绘制；组合保留原有整体布局。

## 调整方式

播放速度：0.5–2 倍。
总长1.8秒，等待0.15秒后开始，末尾静止0.45秒；按统一时间计算每次画面。

预览定位：1200 毫秒。固定演示总长：1800 毫秒。
