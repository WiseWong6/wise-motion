# 点阵连线

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：点阵连线
目的：展示点阵建立后，从一个入口选择多个目标的图形关系。
对象：三十二列、二十八行点阵，左侧方块、十六条细线和十六个固定目标点
动作阶段：
1. 二十八行点阵从上到下错峰显现。
2. 左侧方块弹出，十六条细线由近及远长向目标。
3. 连线抵达后，目标点变蓝、轻弹并出现细环，最终停住。
节奏：3.00 秒完成一次；1 倍速度；匀速。三秒内完成点阵显现、连线生长与命中，末尾留四百毫秒静止画面；速度控件只改变整体快慢。
触发与联动：打开预览后按固定时间表演示；可暂停和定位。
现实类比：整片点阵先建立，再从一个入口依次连中不同位置的目标。
需要保留：保留原点阵密度、十六个目标的位置和远近顺序、连接先于命中、蓝色细线和目标轻弹。
明确排除：去掉下方路由记录、方法与网格说明，以及原场景标题、右侧数值、背景道具和纸底。
对应参考：本地目录「点阵连线」
源码：catalog/effects/illustrations.js 中的 dot-route-illustration
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：从本机 kimi-k3-promo 第二场景提取点阵几何、固定目标及局部动作；整体居中缩放，使用目录底色与明暗墨色，连接与命中保留原蓝色。
