# 瀑布网格黄金绘入

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：瀑布网格黄金绘入
目的：复用瀑布网格黄金绘入的实际几何、连续时序与画面质感。
对象：横纵坐标、主次网格、中心方格、六段格内四分之一弧、依次点亮的扫描节点
动作阶段：
1. 纵横网格错峰延伸，中心第一块正方形在网格绘制一半时出现。
2. 边长1、1、2、3、5、8格的正方形逐块拼接，四分之一弧只绘在各自格内。
3. 黄金弧线完成后，扫描亮点逐个沿内侧前进。
节奏：4.20 秒完成一次；1 倍速度；匀速。固定演示4.200秒，沿用组合0.000至4.200秒的节奏；播放速度可调。
触发与联动：打开后按固定时间播放；可暂停、重播与任意定位。
现实类比：坐标轴与密集网格瀑布绘入，中心方格按斐波那契尺寸接出黄金矩形，内侧节点依次扫描。
需要保留：首格中心与光点重合，主格距27；六块方格拼成13×8矩形，边界贴已绘网格且互不覆盖。
明确排除：不使用原片图像，不随机重排，不让弧线越出所属方格，不把完整组合伪装成单个动作。
对应参考：本地目录「瀑布网格黄金绘入」
源码：catalog/effects/point-domain-flow.js 中的 coordinate-grid-build
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：图形与文字是可替换的示例；保留格内延伸、父子接续和当前时间可重现的动作关系。

## 调整方式
