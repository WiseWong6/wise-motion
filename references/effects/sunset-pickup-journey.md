# 海面上的夕阳

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：海面上的夕阳
目的：保留当前原源码的暖色竖版：飞机接走太阳、收绳巡航，最后进入夜色与星空。
对象：海面上的夕阳的原造型及相关运动主体
动作阶段：
1. 飞机减速入场，绳索展开，座板入水。
2. 太阳握绳，座板托起；飞机负重后回升，滴水反馈接续。
3. 收绳巡航后进入夜色，星点沿原时序显现。
节奏：65.00 秒完成一次；1 倍速度；匀速。保留原作第0秒起的65秒；速度控件统一缩放时间。
触发与联动：打开后按原时间播放；可暂停、重播与定位。
