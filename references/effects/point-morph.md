# 点阵换形

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：点阵换形
目的：固定编号的点在环和矩形点阵目标间连续移动。
对象：固定编号的点集
动作阶段：
1. 点形成第一目标。
2. 各点从原位置插值到新目标。
3. 同一批点完成新形态。
节奏：1.80 秒完成一次；1 倍速度；匀速。约零点一五秒起动，主要动作 1.2 秒，末尾静止零点四五秒。保留原动作先后、错峰间距、回弹或逐字的相对关系；速度控件整体调整。
触发与联动：打开预览后按固定时间表演示；可暂停和定位。
现实类比：固定编号的点在环和矩形点阵目标间连续移动。
需要保留：固定编号的点在环和矩形点阵目标间连续移动。
明确排除：保持点的身份和数量，不重新撒点。
对应参考：本地目录「点阵换形」
源码：catalog/effects/history-patterns.js 中的 point-morph
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：这是从历史源码提炼的结构示例。对象、时长、字形与数值为演示假设；不复刻原作素材、材质和完整场景。 画面统一采用展示片时间线的近黑/暖白与少量彩色强调，白天按同一色相适配；原几何与动作关系保留。

## 调整方式

播放速度：0.5–2 倍。
约零点一五秒起动，主要动作 1.2 秒，末尾静止零点四五秒。保留原动作先后、错峰间距、回弹或逐字的相对关系；速度控件整体调整。

预览定位：1050 毫秒。固定演示总长：1800 毫秒。
