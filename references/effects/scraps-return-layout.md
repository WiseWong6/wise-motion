# 碎片散开归位

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：碎片散开归位
目的：十片印刷碎纸先从中心散开，再回到海报边缘的固定位置。
对象：十片带印刷字与线纹的碎纸，九片浅纸与一片朱红纸
动作阶段：
1. 0.18秒起十片碎纸以28毫秒间隔从834、471向各自的中间位置散开，每片展开0.64秒。
2. 1.08秒起以35毫秒间隔开始回收，每片在0.84秒内从中间位置移向上边、右边或右下角的固定落点。
3. 旋转同时收至固定小倾角，2.24秒后全部归位，保持到2.8秒；已经落定的纸片不继续漂移。
节奏：2.80 秒完成一次；1 倍速度；匀速。每秒12格逐格绘制，动作保持原有先后关系；末尾静止。
触发与联动：打开预览后从头播放；支持暂停、重播、时间定位与整体倍速。
现实类比：像将散落的剪报碎纸重新贴回海报边缘。
需要保留：外散和回收分两阶段，落点固定且分布在海报边缘，保留印刷纹理和短阴影。
明确排除：不在末尾简单淡出，不让碎片持续随机游走。
对应参考：本地目录「碎片散开归位」
源码：catalog/effects/collage-film.js 中的 scraps-return-layout
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：1600×900设计坐标等比呈现在640×360逻辑画板；纸白、炭黑与少量朱红；字片用本地Oswald粗体字形。

## 调整方式
