# 曲线联动

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：曲线联动
目的：用曲线、手柄和运动对象说明控制点变化怎样改变运动快慢。
对象：曲线网格、两根控制手柄、曲线点、匀速与缓动方块，以及后段大曲线与小球
动作阶段：
1. 曲线逐段描出，手柄从直线位置显现。
2. 两根手柄共用一次回弹，曲线点与旁边方块按同一条曲线往返。
3. 接入原作后段的大曲线，小球随曲线高度运动并停在终点。
节奏：4.20 秒完成一次；1 倍速度；匀速。保留手柄回弹和曲线驱动关系，去掉原片外围场景等待；主要动作 3.6 秒，开头停留 0.15 秒，末尾停留 0.45 秒。
触发与联动：按固定时间表演示；可暂停、重播和拖动时间。
现实类比：调整曲线的弯曲程度，旁边方块就按同一条曲线改变快慢。
需要保留：保留两根手柄共用一次回弹的关系、按横坐标反求曲线高度的计算、同程匀速与缓动对照，以及后段超过终点高度再回落的曲线。
明确排除：不把曲线参数直接当横坐标，不让运动方块与曲线点脱节，不加入软件窗口、片尾标题和音轨。
对应参考：本地目录「曲线联动」
源码：catalog/effects/data-comparisons.js 中的 bezier-editor
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：依据本机 Claude 动效演进史的曲线面板与后段大曲线独立适配。前段保留原控制点、一次回弹与往返周期；后段保留原超调曲线，补足一趟行进后停住。属于预设手柄变化演示，不提供鼠标拖拽编辑；使用统一主题与字号，原片不改动。
