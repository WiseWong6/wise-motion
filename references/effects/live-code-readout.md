# 代码参数联动

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：代码参数联动
目的：用代码行、高亮和实时读数展示同一个参数的变化过程。
对象：圆角代码窗口、三个窗口圆点、六行代码、参数读数与底部进度条
动作阶段：
1. 窗口淡入，六行代码按原顺序逐字写出。
2. 形变参数从 0 增至 1，对应代码行高亮，三位小数读数与进度条共用该参数。
3. 读数停在 1.000，进度条填满，对应行恢复普通颜色，窗口保持静止。
节奏：3.00 秒完成一次；1 倍速度；匀速。按原作先写代码、再改变参数的顺序演示；主要动作 2.4 秒，开头停留 0.15 秒，末尾停留 0.45 秒。
触发与联动：按固定时间表演示，可暂停、重播及任意拖动定位；迁用时让读数、进度条和目标效果读取同一个参数。
现实类比：代码运行到形变这一行时，下面的数字和进度条一起更新。
需要保留：保留原六行代码、逐字写出时序、只在参数变化期间高亮第五行，以及读数和进度条取自同一帧形变参数的关系。
明确排除：不单独给数字设置另一条计数动画，不让进度条与读数脱节，不添加滚动日志、光标或原作没有的语法着色。
对应参考：本地目录「代码参数联动」
源码：catalog/effects/live-code-readout.js 中的 live-code-readout
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：从本机 Claude 宣传片右上窗口提取，保留原窗口几何、六行着色器代码、入场和参数时钟。读数采用原作传给形变程序的同帧参数；目录只展示代码窗口，未搬入三维背景、外围标题和声音。字体、字号和颜色沿用目录规范；原工程保持只读。
