# 字色依次轮换

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：字色依次轮换
目的：让短标题从有序进场过渡到连续的色彩强调。
对象：MOTION 原字标、尺度横线、两端年份、七个彩色刻度、打字字幕与背景点阵
动作阶段：
1. 横线从中心展开，背景点阵向外显现，六个字母间隔六十毫秒从裁剪边界升入。
2. 两端年份淡入，七个彩色刻度依次弹出，下方字幕逐字写出并带闪烁光标。
3. 各字按半秒节拍轮换七个色位，字母、尺度线和字幕位置保持，为下一段放大穿越作准备。
节奏：3.00 秒完成一次；1 倍速度；undefined。原片从零秒到二点八五秒的完整开场映射为二点四秒；开头等待一百五十毫秒，末尾停四百五十毫秒，接续下一项的穿越起点。
触发与联动：打开预览后按固定时间顺序播放；可暂停、重播及拖动时间。
现实类比：先展开一把年代尺，再在尺上立起标题，刻度和字幕接着补齐，最后字母轮换颜色。
需要保留：先有尺度线的先后关系；原字形的圆润 O、字距与大小；年份、七色刻度、字幕光标、顶部小字及背景点阵；逐字末尾减速和半秒换色节拍。
明确排除：不将整词同时淡入，不把轮换变色做成渐变扫光；不删掉尺度线、刻度和字幕，不用窄长字体替换原字标。
对应参考：本地目录「字色依次轮换」
源码：catalog/effects/reel-opening.js 中的 char-color-cycle
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：按本机 Claude 动效演进史的原源码重写，固定 MOTION 使用随包 Oswald Bold 矢量字形，英文字幕统一使用 Oswald Bold；夜间恢复原配色，白天适配明底，纹理沿用目录的静态薄层。

## 调整方式

播放速度：0.5–2 倍。
原片从零秒到二点八五秒的完整开场映射为二点四秒；开头等待一百五十毫秒，末尾停四百五十毫秒，接续下一项的穿越起点。

预览定位：2045 毫秒。固定演示总长：3000 毫秒。
