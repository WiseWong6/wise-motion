# 按钮操作反馈

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：按钮操作反馈
目的：让操作、处理中状态与结果形成可见关系
对象：指针、按钮、进度与完成结果
动作阶段：
1. 模拟指针靠近并按下按钮。
2. 按钮反馈后，显示固定时序的处理进度。
3. 处理完成，显示成功确认。
节奏：4.20 秒完成一次；1 倍速度；末尾减速。约零点一五秒起动，主要动作 3.6 秒，末尾静止零点四五秒。保留原动作先后、错峰间距、回弹或逐字的相对关系；速度控件整体调整。
触发与联动：固定演示指针移动与按下按钮，再出现处理进度，最后显示完成结果。
现实类比：按下按钮、等待处理、看到结果
需要保留：模拟一次按钮操作，随后显示进度和成功结果。
明确排除：结果必须发生在操作之后，处理中不能被跳过。
对应参考：本地目录「按钮操作反馈」；所用动作：按钮点击换状态、进度填满淡出、淡入上移
源码：catalog/effects/compositions.js 中的 interface-feedback
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：使用自有抽象卡片与文字演示；对象内容、尺寸和总时长可调整，动作结构不变。 画面统一采用展示片时间线的近黑/暖白与少量彩色强调，白天按同一色相适配；原几何与动作关系保留。

## 调整方式

播放速度：0.5–2 倍。
速度变化：匀速、末尾减速、平缓往返。

预览定位：2347 毫秒。固定演示总长：4200 毫秒。

- [自编源码](../../catalog/effects/compositions.js)，注册名称：`interface-feedback`。

### 可替换内容

通过组件 `content` 为当前实例赋值；字段含义与字体、宽度限制见 [组件说明](../../REMOTION.md)。默认内容如下：

```json
{
  "states": [
    "开始整理",
    "正在整理",
    "整理完成"
  ],
  "result": "✓ 已整理完成"
}
```

- states（按钮三个阶段）：3–3 项，每项最多 12 字。
- result（完成提示）：最多 24 字。

## 示例：文件展开输入与发送折回

动效说明：按钮操作反馈
示例样式：文件展开输入与发送折回
目的：文件卡展开为输入框，逐字输入，鼠标点击，环形处理后勾选，卡片折叠并上移。
对象：文件展开输入与发送折回
动作阶段：
1. 按固定帧时钟建立示例对象与初始位置。
2. 文件卡展开为输入框，逐字输入，鼠标点击，环形处理后勾选，卡片折叠并上移。
3. 在第188帧保留此片段的结束姿态；重播回到同一起点。
节奏：6.30 秒完成一次；1 倍速度；匀速。189帧，30帧/秒，共6.3秒；分段时间映射见动作参数说明。
触发与联动：按固定时间顺序播放，支持暂停、定位和重播。
现实类比：文件卡展开为输入框，逐字输入，鼠标点击，环形处理后勾选，卡片折叠并上移。
需要保留：保留原文件名、输入文字、Thinking与Tools文字及等宽字；原局部时间0–119按最新输出346–534的188间隔映射；形变27–49、打字44–73、按压77–82、处理81–94、成功94–100、折叠99–121。原片在局部119截断，保留原末帧淡出程度，不补造123帧尾部。
明确排除：不把逐单元运动简化成整体淡入、缩放或随机漂移；不添加音轨。
对应参考：本地目录「按钮操作反馈」
源码：catalog/effects/lego-kingdom.js 中的 lego-file-editor-send
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：保留二维源图形，所有姿态由当前帧直接求值；中文字体的替代边界见来源说明。

使用同一动作定义，设置 `variant_id: "lego-kingdom-file"`；目录和相关动作弹窗均可切换。
