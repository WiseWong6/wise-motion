# 界面操作反馈

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：界面操作反馈
目的：让操作、处理中状态与结果形成可见关系
对象：指针、按钮、进度与完成结果
动作阶段：
1. 模拟指针靠近并按下按钮。
2. 按钮反馈后，显示固定时序的处理进度。
3. 处理完成，显示成功确认。
节奏：6.50 秒完成一次；1 倍速度；末尾减速。改变速度变化时保留动作阶段与先后关系。
触发与联动：固定演示指针移动与按下按钮，再出现处理进度，最后显示完成结果。
现实类比：按下按钮、等待处理、看到结果
需要保留：模拟一次按钮操作，随后显示进度和成功结果。
明确排除：结果必须发生在操作之后，处理中不能被跳过。
对应参考：本地目录「界面操作反馈」；所用动作：缩放进入、数字增长、局部高亮
源码：catalog/effects/compositions.js 中的 interface-feedback
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：使用自有抽象卡片与文字演示；对象内容、尺寸和总时长可调整，动作结构不变。

## 调整方式

播放速度：0.5–2 倍。
速度变化：匀速、末尾减速、平缓往返。

预览定位：3840 毫秒。固定演示总长：6500 毫秒。
