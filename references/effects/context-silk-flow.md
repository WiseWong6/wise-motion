# 光丝传递词语关联

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：光丝传递词语关联
目的：适合表达上下文参考和信息交换；从光丝显现开始，不带前面的界面入场。
对象：固定弧线上的细光丝、词语框、下方竖向输出
动作阶段：
1. 词语框已就位，光丝从端点显现。
2. 亮纹沿同一条固定弧线行进。
3. 第二种样式继续沿下方竖向光丝输出。
节奏：2.35 秒完成一次；1 倍速度；匀速。默认沿用成片1.3倍节奏，约2.35秒。
触发与联动：打开后按固定时间播放，可暂停、重播与任意定位。
现实类比：多根细光丝沿固定弧线显现，再持续流动；包括上下文汇入与交错关联加下方输出两种样式。
需要保留：固定曲线、不缩放形状；保留原随机种子、线宽、亮纹与间歇流动。
明确排除：不添加未选片段，不改原几何和材质，不以整体淡入替代内部动作。

源码：catalog/effects/knowledge-video.js 中的 context-silk-flow
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
