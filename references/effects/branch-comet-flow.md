# 沿枝流光

以下动效说明由统一定义生成。示例对象和时长是可调整的假设，结构要求需要保留。

动效说明：沿枝流光
目的：独立复用沿正在形成的分支持续传递的亮尾。
对象：三组曲线亮尾、头部光点及径向辉光
动作阶段：
1. 三路光流等待各自路径开始生长后出现。
2. 头部和短尾沿同一曲线前进，前端受当前枝干长度限制。
3. 各路到原抵达时刻分别停止，不保留静态亮尾。
节奏：5.35 秒完成一次；1 倍速度；匀速。独立演示 5.35 秒；原路径生长、相位和逐路停止时间整体前移 0.65 秒，不压缩相对时间。
触发与联动：打开后独立播放；可暂停、重播和任意定位。
现实类比：三条路一边延长，一边有小彗星沿已成形的路段向外传递。
需要保留：保留三条原曲线、每秒 0.8 周相位、三路错相、0.3 路程尾长和已生长范围限制；头部辉光与亮芯同位。
明确排除：不替换成沿完整折线匀速前进的单点，不让亮尾越过当前枝尖，不另画直线尾巴。
对应参考：本地目录「沿枝流光」
源码：catalog/effects/radial-branch-flow.js 中的 branch-comet-flow
来源与许可：自编示例，AGPLv3；Anime.js 4.5.0，MIT。
关键假设：直接抽取组合光流层；与组合共用曲线和时钟，仅去掉前 0.65 秒等待。独立只创建三组亮尾，不创建枝干或其他组合层；原目录配色保留。
