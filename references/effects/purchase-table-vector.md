# 购买表格突出一行

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：购买表格突出一行
目的：适合讲解表格一行如何成为向量；横向完整八列，列间保留宽裕间距。
对象：八列用户、三行购买记录、行高亮和数字行
动作阶段：
1. 八个用户与猫粮购买记录出现。
2. 猫砂和狗粮记录按同一列顺序填入。
3. 突出猫粮一行，并展示完整的八个数字。
节奏：5.42 秒完成一次；1 倍速度；匀速。默认以成片的2倍速度播放，约5.42秒；播放控件的1倍代表此默认节奏。
触发与联动：打开后按固定时间播放，可暂停、重播与任意定位。
现实类比：三行八列购买记录在宽屏中展开，猫粮一行亮起，其余两行变暗，完整数字行提到下方。
需要保留：三行八列原始数据不变；横向铺开，列中心间距160像素；不压成三列，不把记录转置。
明确排除：不裁去列或压缩列距，不以整体淡入替代内部动作。
对应参考：本地目录「购买表格突出一行」
源码：catalog/effects/knowledge-video.js 中的 purchase-table-vector
来源与许可：原码提取与接入，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：内容和数据为固定讲解示例。适合讲解表格一行如何成为向量；横向完整八列，列间保留宽裕间距。

## 调整方式

播放速度：0.5–2 倍。
默认以成片的2倍速度播放，约5.42秒；播放控件的1倍代表此默认节奏。
