# 字片折落归位

以下说明描述现有实现，示例对象、时长和动作结构可按需求修改；以用户明确要求为准。

动效说明：字片折落归位
目的：带纸背与切边的字片先后翻落，重新排列为上下两行。
对象：上下两行WISE与MOTION剪纸字片、黑白相接的撕边纸底
动作阶段：
1. 开场0.25秒后，上行四片字以75毫秒间隔开始翻落；每片在0.65秒内从上方进入，并从负1.8弧度展开纸背。
2. 0.62秒后，下行六片字以95毫秒间隔从右下方进入，在0.72秒内从2弧度翻回正面；每片保留不同倾角和离纸阴影。
3. 1.82秒前完成上下两行排列，保持到2.2秒；上行炭黑字配浅纸切边，下行浅字配炭黑切边。
节奏：2.20 秒完成一次；1 倍速度；匀速。每秒12格逐格绘制，动作保持原有先后关系；末尾静止。
触发与联动：打开预览后从头播放；支持暂停、重播、时间定位与整体倍速。
现实类比：像把剪下的字母逐片翻回正面并排到海报上。
需要保留：两行字的先后关系、底边折叠轴、纸背、切边与固定微小倾角；上行有轻微过冲。
明确排除：不以纯透明度淡入替代翻折，不把字片做成整块卡片。
对应参考：本地目录「字片折落归位」
源码：catalog/effects/collage-film.js 中的 cutout-type-fold
来源与许可：自编示例，Apache-2.0；Anime.js 4.5.0，MIT。
关键假设：1600×900设计坐标等比呈现在640×360逻辑画板；纸白、炭黑与少量朱红；字片用本地Oswald粗体字形。

## 调整方式

播放速度：0.5–2 倍。
每秒12格逐格绘制，动作保持原有先后关系；末尾静止。

预览定位：2000 毫秒。固定演示总长：2200 毫秒。
