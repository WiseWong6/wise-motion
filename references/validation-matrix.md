# 验证范围与命令

检查与改动范围相称。默认不启动浏览器或截图，区分文件检查、实际渲染与人工播放；未执行的不能报告通过。

| 范围 | 必要检查 |
| --- | --- |
| 需求与检索 | 明确动作、多段动作分别查询、明确禁项、没有匹配；说明覆盖和缺口 |
| 查看 | 默认输出用途、预览、真实源码入口、依赖、参数；变体与详细内容限制一致 |
| 源码导出 | 普通组件、含素材组合、独立工程；生成文件与目录复制逻辑一致，已有文件不覆盖，任意工作目录可调用 |
| 组件接入 | 内容字段与限制、帧和时间换算、循环、透明背景支持、素材与依赖路径；不改原绘制实现 |
| 目录维护 | 生成文件与定义一致、文档链接、许可与安装入口；本机补丁不进入发布包 |
| 播放或视频导出 | 仅在任务要求时运行；核对暂停、定位、重播、变速与声音同步，交付实际结果 |

以下命令在技能实际目录运行。检索、查看和源码导出本身只需 Node.js；维护检查使用项目现有开发依赖，字体覆盖检查另需 Python 3。

| 改动 | 命令与边界 |
| --- | --- |
| 技能说明、接入说明或安装配置 | `python3 scripts/verify_project_skills.py` 检查文件、手动调用配置和资料入口；`npm run check` 另检查文档章节链接、目录定义、生成文件、许可、脚本语法和字体覆盖 |
| 检索、查看、导出 | `npm run test:files -- tests/matching.test.mjs tests/source-delivery.test.mjs`，覆盖禁项、无匹配、变体、任意工作目录、源码一致和已有文件保护 |
| 播放器与逐帧接入 | `npm run check:remotion`；另按修改范围选择声音、加载、缩略图等测试 |
| 其他局部修改 | `npm run test:files -- tests/具体文件.test.mjs`，明确列出受影响文件 |
| 发布程序 | `npm run test:publish`，使用本机包管理器和本地模拟仓库，不向公网发布 |
| 历史来源记录 | `npm run check:history`，需要私有档案；修改后的生成步骤见 [历史来源](history.md#维护与验证) |
| 全量回归 | `npm test`，包含普通检查、历史一致性和全部测试，需要私有档案及相关原作文件 |

局部、播放器、发布和全量测试共用 `test:files`，最多同时运行四个测试文件，并保留包管理器提供的环境。不要把全量通配符当作局部测试命令；只运行单个文件时也通过这个入口。

修改目录定义或绘制源码后，先运行 `npm run build` 更新生成文件，再执行相应检查。只改说明或测试命令无需重建播放器。内容盘点可运行 `node scripts/audit-content.mjs`，它只读输出线索，不证明内容接口或实际画面正确。

文件检查与模拟页面测试通过，只能说明对应自动检查通过；真实浏览器播放、视频渲染和新会话实际调用分别报告。人工播放步骤见 [验收说明](../tests/manual.md)。
