# 参考目录维护

仅在修改目录展示、分类、复制输出或收录动作时读取。新作品使用自己的设计方向。路径与命令相对实际工作副本根目录；原目录的命令不得拿来直接写入迁移副本之外的位置。

## 可复刻提示词与源码

- 目录复制的提示词直接写对象、构图、配色、动作步骤、时长、触发和参数。删去原片范围、观看定位、关键假设、审查结论、验收状态、迁移状态、本机路径和来源许可等内部说明；出处与许可保留在独立说明及源码中。
- 数字参数从实际绘制代码核对，不能用“沿用原作”“见本机源码”代替制作要求。参数不足时交付该案例真实实现文件及其引用的文字依赖，不能把只调用本机目录的预览页当作效果源码。
- 正式目录和新增动效的复制输出必须提供可运行的 Remotion 用法、真实绘制源码、依赖与素材清单，并在独立工程验证；不能只给调用本机目录的外壳。复制提示词明确要求动效使用 Remotion，目录界面不作技术绑定。历史页签已下线，原作源码与迁移依据仅用于追溯和回归检查；来源工程保持只读。

## 保真迁移与副本保护

- 迁移先从当前完整工作区复制原版基准和工作副本，包含未提交的新效果、字体与素材；不只复制最近一次提交。使用独立实文件，记录清单与校验值，禁止用共享可修改文件的链接代替副本。
- 独立迁移验证期间，原目录与原历史状态保持只读。先审查构建脚本的所有输出位置，将副本外的历史、索引和生成物写入改为副本内或验收目录；不得恢复已清空的历史记录。技能规则可以按授权直接在权威源更新。
- 保留原构图、运动公式、原设计时间映射、逐格节奏、材质、字体和内部像素尺寸；目录外观、搜索、分类不随迁移重新设计。复杂效果先选代表项，再按验收记录覆盖条目及变体。
- 技术检查、画面对比、视频导出与用户验收分别记录。条目有未解决差异就不能登记为完成，不能用依赖安装成功或类型检查通过代替保真结论。核对原目录校验清单后交付独立入口；用户明确授权正式替换时，先检查并行修改，保存可回退原版，再替换并检查实际正式入口。
- 迁移路径、进度、检查结果和产物清单放本次任务的维护／验收记录，不硬编码进可复用技能。无服务器依赖的目录保持本地直开；Remotion 开发或导出所需服务只在实际需要时启动并及时清理。

## 目录视觉与分类

以下规则用于参考目录本身的展示。新作品的视觉方向按用户意图和当前工程设计确定，不自动套目录主题或旧视频主题。

- 普通结构示例统一沿用近黑底、暖白细线与少量彩色强调。白天只调整底色和文字/线条对比，保留色相；颗粒与暗角为静态薄层。
- 纯英文、纯数字使用本地 Oswald Bold；中文正文和辅助标签使用思源黑体 Light，动效内中文主标题、分类与章节标题允许使用思源黑体 Bold。画板字号统一为辅助 12、正文 16、局部标题 24、次标题 32、主标题 48、大读数 64 像素，细密刻度使用 10 像素；图形缩放后按实际画板大小补偿。字形造型、词云和动作中连续改变的大小保留其结构。不混用其他拉丁字体。
- 鲜明插画保留原色和材质，包括螺旋丸、牛皮纸与蓝晒等物件，不能用全图滤镜统一改色。
- 名称描述可复用的运动机制，避免把手机、年份、片名等示例内容写进名称；具体对象和来源保留在说明中，旧名称保留为搜索词。分类名称与归属以 `catalog/registry.json` 的分类定义和 [生成索引](index.md) 为准，不另维护旧分类清单。数字与图表、扫描与信号分开；强调与配色、光效与氛围分开；径向散射归粒子与流动，单画面的布局调整不归画面转场。单个动作、插画单图、组合片段各自分组；历史页签保持下线，已迁入条目只使用正式入口。

## 本地包与边界

- 权威定义为 `catalog/registry.json`；页面数据、轻量索引和逐项说明均由 `npm run build` 同时生成目录数据和 Remotion 播放器，修改定义后一起生成和检查，避免两套描述。
- 每项提供非空的 `recommendation`，说明适用关系及与相近条目的取舍；它用于检索理由，不以名称或泛泛形容代替。结构检查发现缺项即失败。数量以目录定义为唯一来源，README 概览和 `CATALOG-STATS.md` 自动生成。
- 标准动作、插画和组合的数量以当前目录数据为准。原作引用保留在历史来源记录中，子动作抽取不等于完整原作封装；文稿需分开处理内容单位、入退场、清晰停留和讲述节拍。日常构建与检索不依赖私有历史档案；档案单独通过 `npm run build:history` 生成、`npm run check:history` 核对。
- 插画允许保留自身动作；带动作的插画在 `actions` 中关联动作目录条目，相同运动方式优先使用已有动作的示例，并通过 `action_variants` 指向准确示例。缺少的动作独立登记，与插画通过 `source.factory` 共用实际绘制，不复制实现、不强制静态化；静态主体不虚构动作。预览、缩略图和复制输出均按所选示例的绘制入口、时长、素材与配色执行。
- 组合先从原实现拆出真实子动作，再对照已有实现查重；相同运动机制复用已有动作，缺失项才新增。独立动作与组合共用绘制函数，只建立自身节点。相关动作直接开弹窗并自动播放，关闭回到原组合状态。
- 书法、颗粒横笔与多种材质接续的精修按需读 [精修方法](material-refinement.md)：分别核对起收笔和长短倾角，不强拉不对应的碎墨；按实际开销准备画面，保留最后定位和暂停意图。完整材质演化组合及七个独立动作共用真实绘制，保留纸底、灰墨和图形字标。
- 正式目录保留浏览器原生样式和原绘制函数，由 Remotion 控制帧，Anime.js 4.5.0 保留原缓动计算；新增动效按 [Remotion 制作与保真接入](remotion-production.md) 编写。正式目录无需原历史工程、服务器或运行时网络。本机视频预览与字体补字须分别记录来源，不能把旧视频的来源校验值改写成新版本。
- 自有技能和源码使用 AGPLv3；Anime.js 保留 MIT。GSAP、Jitter、Amotion 与未核实素材只作为参考入口，不能当成已许可的内置源码。
- 通过 [播放接口](runtime-interface.md) 交接可播放、暂停、重播、定位时间和释放资源的参考。主预览、相关动作弹窗和复制页面默认从头自动播放，不根据系统动效偏好降级或暂停，不显示相关提示或开关。保留手动暂停、时间定位、目录页面隐藏时暂停及仅恢复原本正在播放内容的规则。交互参考提供固定演示顺序，目录自身交付参考预览；作品实现和成片按 [阶段制作方法](pipeline-methodology.md) 完成。

界面交互依据见 [界面设计说明](apple-hig.md)；目录体验按 [人工验收步骤](../tests/manual.md) 检查。
