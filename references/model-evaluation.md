# 模型评测协议

检验模型能否使用真实目录代码完成内容替换、装配和渲染。工具验证、模型表现、人工观看分别报告；没有调用某个模型，不能给它打分。

## 固定运行条件

- 记录平台、可调用的准确模型版本、工具权限、上下文限制、预算、最长运行时间；不能只写 GLM、HY4、Grok 这样的家族名。同一运行框架、同一依赖与浏览器版本。
- 三个待测模型和一个强模型对照，每模型每任务至少两次全新目录运行。先做整片和换内容，共十六次；加叠层任务共二十四次。这是初步稳定性测试，不足以给模型排总榜。
- 固定完整六至八句字幕、期望保留的名称与数值、约二十秒目标及允许偏差。缺少完整字幕时先标待提供，不能用几个短语冒充原片评测。
- 记录准确源码文件摘要，包含未提交与新文件；仅记录提交标识不能描述当前工作区。冻结输入提示词、初始计划和安装素材摘要。
- 产物放在技能之外的 `state/wise-motion/eval/<日期>/<模型>/<任务>/<轮次>/`。评测者的基线和日志与模型可写工程分开；不要依赖可被重装刷新的安装清单作为初始证据。源码只读。
- 不人工干预单次运行；故障由模型自行处理。两次运行互不读取对方产物。每次计划检查都由外部运行器记录工具调用、输入版本、退出结果和时间；漏记时总轮数标为未知。

## 三个任务

| 任务 | 输入与约束 | 必须留下的证据 |
| --- | --- | --- |
| 整片 | 相同字幕、约二十秒、使用 wise-motion，自行设计分镜 | 计划、生成入口、独立原创源码、逐次检查、每镜可读时段样帧与可播放短片 |
| 只换内容 | 相同已有计划；指定某镜更换文字，不允许改绘制源码 | 初始与最终计划；差异仅在指定 `content`；其他镜头及素材摘要不变；替换前后同时间的画面 |
| 一镜多层 | 原创背景加复用标题，保持原动作 | 独立背景组件、`layers` 计划、真实叠层样帧；更换标题后重新装配，背景源码保持原样 |

第一轮优先做“只换内容”，用已支持的普通文字动效定位模型是否读了槽定义。不要等待粒子或整个目录透明化后才开始测试。

## 留证与只读评分

在评测者环境把 `WISE_MOTION_RENDER_DIR` 设为源码外评测根目录，所有路径传绝对路径。文件写入使用新名称，已存在的证据不会覆盖。

```sh
node scripts/eval-evidence.mjs snapshot <工程/public/wise-motion> <评测者/baseline.json> [初始计划.json]
node scripts/eval-evidence.mjs check <工程/plan.json> <评测者/check-01.json>
node scripts/eval-plan.mjs <工程/plan.json> <评测者/baseline.json> <评测者/check-01.json>
```

收集器保存输入和结果；评分器只读取，不启动浏览器、不生成样帧、不改文件。评分输出包含结构错误、各实现方式数量、素材新增/删除/改写、源码是否变化、已记录的检查次数、原创待实现项，以及初始计划存在时的内容差异约束。`contentOnly` 只证明计划和素材差异，仍须核对究竟改了指定哪一镜、实际组件是否绑定该计划。没有外部完整工具日志时，记录次数不等于总尝试次数。

渲染检查必须使用最终生成组件，核对计划、入口、实际组件和画面一致。不能只根据模型填写的 `reuse` 标签计作真实复用。没有渲染证据时，评分器返回 `unverified` 或 `needs-render-and-review`，绝不返回整体通过。

每镜至少取建立、可读、退出三个时刻，并提供短片核对节奏。不要固定取最后一帧：粒子会收拢退出，末帧可能有意为空。噪点底不算主体；必须检查期望的文字或图形区域。换内容前后用相同帧、种子、字体和尺寸比较；普通文字可检查实际可见文本、边界与遮挡。画布像素变化仅证明输入影响画面，不能证明拼写正确，粒子字形仍需人工看样帧。

## 判定与记录

- 两轮内通过计划检查可作为效率目标，缺日志标未知。结构和语义分开计分。
- “只换内容”要求指定镜头全部通过内容参数完成，素材与其他镜头不变；“叠层”要求真实底层可见、上层可读、重新装配后原创背景保留。
- 复用比例只报告，不作为开放创作任务的七成门槛。已知可复用的固定测试可以另设明确覆盖要求，不能为了达比例选错动作。合理原创允许 `nearest: null`，但要写检索和不适用原因。
- 失败登记：未查字段、变体选错、长度错误未处理、用原创逃避普通内容替换、改共享副本、生成入口与计划不符、缺少渲染主体、字体/遮挡、节奏不合理、工具或环境失败。保存错误原文，不混为模型能力问题。
- 人工分别给文字准确可读、节奏停留、视觉统一打 1–5 分，并附具体帧或时间证据。未观看一律留空。模型总体结论必须同时有执行记录、最终画面和人工评分；单次顺利不证明稳定。
