# Wise 视频阶段操作

## 阶段选择

按文案 → 静态画布 → 动效 → 合成分离内容、视觉、运动与装配。修改已有工程只回到问题所属阶段，不重做已确认内容。片型与工程栈分别判断：有旁白教程以语音和逐句画面组织叙事；无旁白作品以图形、事实来源和节拍组织叙事。新动效及新视频中的动效统一使用 Remotion，制作时读取 [Remotion 制作与保真接入](remotion-production.md)。参考目录界面、静态画布和普通网页的技术不受此限制。维护既有工程保留原栈：已有 HyperFrames 工程使用保护合同，已有 Remotion 或 HTML 逐帧装配工程沿用自己的时间表；本规则不自动发起迁移。

当前任务授权和交付范围优先。HTML 静态预览无服务器依赖时 file:// 直开；确需服务时说明原因，复用已有服务并清理本次进程。帧工程使用现有预览入口。

| 工程 | 执行方式 |
| --- | --- |
| 参考说明、静态画布或普通网页 | 在对应阶段工作，不建立视频合同；页面界面不要求 Remotion |
| 新动效或新视频中的动效 | 使用 Remotion；预览和导出共用由帧控制的组件，不另建自由运行的动效时钟 |
| 用户本次明确指定的新 HyperFrames 视频工程 | 该次技术选择优先，用 `$hyperframes` 路由并读取或建立 `BRIEF.md`；先试算合同初始化，核对基线和时间权威后写入 |
| 已有 HyperFrames 合同工程 | 使用真正拥有当前画面源的 `wise-video.json`，执行 [制作保护约定](production-contract.md) |
| 无合同的旧 HyperFrames 工程 | 对实际交付目录运行 `validate --level contract --legacy-ok`，另核对源、时间表、音频和成片；不自行补合同或迁移 |
| 已有 Remotion 或 HTML 逐帧装配工程 | 保留现有帧表、时间表与工程栈，使用自己的检查和导出命令 |

用户意图归任务说明或 `BRIEF.md`，镜头归故事板，旁白归脚本，视觉归画布，时间归音频元数据或帧表。合同只索引和保护这些来源，不复制内容或秒数。时间权威标明语音、音乐或视觉及草稿/锁定状态；切换锁定权威、改变保护资产或扩大范围须有授权。

## 文案与事实

- `SCRIPT.md` 是教程底稿；平台差异在 `SCRIPT-<platform>.md` 分离。滚动教学的底部字幕就是讲述稿，画面随讲述推进。
- 屏幕字幕与配音稿由同一底稿派生：屏幕可按约定省句末标点，送语音合成的文本保留气口标点，由映射维护；实际词句改变时重合成并重新对齐，标点投影变化也须核对听感。
- 无旁白作品先写素材源、时长、比例、参考与叙事节拍；每个数据或主张写清口径和来源。未独立核实的结果明确注明，不能用问号掩盖无依据数字。
- 标签、案例与讲述逐句对照，案例须具体且因果成立，不增添无来源口号。只诊断另一产品或 Skill 的任务不修改被诊断对象。
- 确定是否配音、音乐和音效；无配乐无音效可以是完成状态。

## 画布与设计真值

- 布局数值以当前画布 `safe-area.md` 为准，已有 Wise PPT 工程的主题以 `~/Documents/Developer/wise-ppt-development` 的配置为准，其他作品按当前已确认设计；组件引用先确认编号体系。
- 空间测量、尺寸保护、列间留白与图文对齐按 `wise-motion-dna.md` 执行。新稿的字号与插画尺寸按阅读需求确定；已确认尺寸不因“利用空间”被顺手放大。
- 演进只改授权的状态和内容；剥离复用的造型、数量、顺序与参数作为基准保护，差异明示。
- 换主题逐值核对颜色、线宽与字体角色；检查原底上的深浅元素是否消失，保留原素材颜色。未核实授权的字体不复制。
- 样张用内嵌图形、页面结构与局部样式呈现；不把截图位图当作可编辑画布。
- 在现有动作计划标明本镜必须看清的案例细节和动作落点，按 [视觉与动作方法](wise-motion-dna.md) 检查当前状态的信息量、原始比例、裁切范围与显示尺寸。复用已确认案例时保留可运行画面和内部动作，不降为缩略图再用外壳动画代替。
- 数值断言检查数量、居中和安全边界；它们不能替代间距与观感验收。探索稿使用副本，基线用哈希或已授权的提交引用保护。

## 动作原则与实现工具

先按 [导演设计方法](director-design.md) 给镜头分配识别、比较或操作任务与相对时长，在原动作计划写清起势、推进、落点、结果阅读窗与下一镜视线锚点；再写主体、意图、受力、目的地和感受，选择实现规则；动作质量与空间判据见 [视觉与动作方法](wise-motion-dna.md)。

- 动作机械、僵硬、无重量、意图不清，或用户明确要求 Disney 原则时，且当前项目存在可用入口，才读取 `$disney-animation-rule-skill`；字幕位置、普通排版、检查和渲染不加载它。每个动作窗口选 1–3 条原则，写动作阶段表（phase table）：意图、相对时长、边界姿态、受力与夸张边界。入口不可用时用本技能方法继续；用户明确指定该技能时说明限制，不自动安装。
- 新动效使用 Remotion 的当前帧计算画面。复用旧效果时保留原绘制、运动公式、缓动和素材，先验证保真接入，再考虑另行获准的改良；不能把迁移当作重新设计。
- 维护既有 HyperFrames 工程或用户本次明确选用该流程后，读取 `$hyperframes-animation` 并映射 2–4 条原子规则，所有动作汇入单一主时间线。在此工程内忽略参考提出的 Remotion、Puppeteer 或第二渲染器路线。既有帧工程沿用自己的确定性取样接口。

## HTML 动效接口

以下用于维护既有 HTML／HyperFrames 页面，或用户本次明确指定的例外流程；新动效遵循 Remotion 制作指南。其他既有工程沿用已确认接口。

- 每帧一条可暂停、可跳转的时间线，注册到 `window.__timelines.<frame>`。合成按时间取样，不改动效设计。
- 采用显式初末态和 `fromTo + immediateRender:false`，验证倒序、乱序及重复取样；写法本身不保证确定性。
- 保存原稿透明度和变换，淡入回到原值；已有变换的图形避免被动画覆盖。缓动按面积与角色分档。
- 放映页初始化首态，入页先复位再播放；总览与打印克隆前快进终态，克隆后恢复原取样状态，避免检查或复制改变当前预览。
- 字体加载后建立时间线。预览可降级并记录原因；导出遇时间线失败中止，不能以静态壳冒充成功。预览遵循当前工程已确认规则；本技能参考目录默认自动播放，不根据系统动效偏好降级或暂停。导出采用明确固定配置。
- 从本技能的 `references/index.md` 与 `catalog/registry.json` 借鉴现有动效，可改良、跨类组合或发散；旧 `~/Documents/Developer/scenes/motion-catalog/` 仅作为补充历史来源。实现涉及不确定技术时查官方文档和许可；登记仅在当前任务要求时进行，不自动回写其他库。
- 小步修改保持可回退。回滚恢复旧文件、移除本轮新增与残留调用，再检查初始化和相邻交接；不得覆盖用户已有改动。

## 教程动效与语音

- 静态稿确认后，先取得已确认声音的真实语音与词点，再定最终动作时长。
- 新教学场景从空白主体建立；真实原件展示可完整呈现，跨镜持续主体保留身份。逐句首态、入场、强调、收声与交接按 `narrated-tutorial-review.md` 检查。
- 字幕按实测字点显影，一行居中；语音与画面按含义对应，使用解释性的揭示、描线、重组或焦点转移；结果阅读窗按 `wise-motion-dna.md` 记录阅读对象与结束点，保持文字和比较关系稳定，不为填满旁白时长追加无意义循环。
- 同组动作保持一致节奏语言，各层的起止与响应按因果错开，同一时刻只有一个强化主体；连续运动和动量衔接按 `wise-motion-dna.md` 执行。先建立对象再否定或描线，中心词与标题终位分开安排。
- 相机与物体分离，转镜后维持清楚的观察位置与持续的主体进展。自然现象先按反射、重力、接触等规律建模，风格化参数在模型上微调。
- 画面建议先核对逻辑与物理，必要时提出保留原意的替代。画面空或静止先查缺失表达，不添无来源文案或提前揭示下一句。

## 合成与音频制备

- HyperFrames 只包根容器、固定放映态并收编单一主时间线。防止页面自动播放或翻页监听与逐帧取样竞争；导出隐藏控件，切点与阅读时长遵循当前时间权威；动作交接的空隙在源动效修正，合成不得补定格或黑场来等下一段。
- 配音沿用确认的供应方、音色、参数与速度；`doubao-tts` 仅在已选用时使用。成功产物复用，不重复计费。
- 少量改句优先同参数替换，未改语音逐字节保留；若跨批次或累积替换造成声音、速度漂移，先核实原因，再在授权范围内统一重合成受影响段，不固定句数阈值或强换默认参数。
- Whisper 等词级对齐用于字幕与动作定位，不直接作为裁音边界。没有异常停顿时连续保留原音；需剪长停顿时只剪波形和听感确认的静音区，核对头尾辅音、尾音与气口。
- 逐句导出保留足够前后衬底，核对保留区间无遗漏、重复或乱序。整句及句内短窗字速分别检查，疑似识别错误先回听，异常句修复或说明豁免。
- 全片统一单一字幕机制，句末退场与下一句不重影，续帧不重打。字幕、配音准备文本和动作映射由同一底稿维护。
- 音效与画面共用接触事件，记录时间、位置和强度；音效选择与响应按 `wise-motion-dna.md` 执行；暂停或拖动不补播旧事件。音效密度、间距和响度从简，导出后再核对混音，浏览器听感不足以代签成片。

## 变体与输出

- HyperFrames 变体声明 `allowedDiffs`，共享段保持一致，独立命名输出，非默认构建完成后恢复默认。
- 风格切换一次更新全部层，保留播放进度，适配参数独立。比例变化重排叙事和节奏，适合裁切的段落可复用，关键段单独设计；共享事件语义，时间从各版权威表推导。
- 语言或文案变体由主源确定性生成；逐条替换断言唯一命中，显式全局替换声明预期次数。字体、字号与显影速度随语言参数一起派生，不手改副本。
- 只差音轨或结尾时可复用正文视频流；相同画面的流哈希应一致。音频需验证实际封装偏移；只有无损复制时才用源轨字节哈希判断一致，有重编码时检查时序与信号相关性。
- 大分辨率导出在工程支持的构建层等比缩放，不额外重排；检查阈值随尺度换算。导出逐帧取样，皮肤和比例参数显式传入并断言，避免录入实时播放卡顿。
- 动作库登记和教学取样使用原速时间；发布倍速单独标明，同步换算字幕、音效和显示时长。

## 确定性帧工程

- Remotion 的帧表或 HTML 装配链的时间表是唯一时间权威。帧号与秒数按帧率换算，场景、音效与转场绑定该表。
- 维护已有 HTML 场景时可沿用 `window.__ready` / `window.__render(t)` 接口，公共视觉与动作放共享层；装配转场偏移从权威表推导，不手抄秒数。
- 先做代表性短段确定方向，再全量制作。用工程预览迭代；按交付节点与稿号隔离输出，水印仅在当前需求要求时使用。
- 场景、场景片和成片分层缓存，只重渲受影响场景及装配步骤。本次无用可再生缓存清理，验收产物保留；不默认开双端口或长期进程。
- 未要求静止的连续视频全区间按 `validation-matrix.md` 扫描停顿、检查动量与唯一强化主体；阅读段也覆盖，区分有阅读任务的结果停留与无内容等待，不用装饰运动掩盖后者。用户明确要求停留、交互反馈或单个参考按自己的动作目的检查。检查倒序、乱序和同帧同画，用数值或像素比较；截图、浏览器操作及视觉复核按授权执行。
- 程序化配乐仍核对采样、依赖和来源权利；响度目标按当前平台与任务决定，不把单片目标当通用标准。

## 素材、封面与交付

- 官方没有的界面不伪造，官方截图不改原字体；下载素材与工程副本核对哈希。录屏字体已固定，需要表达变化时用局部放大或镜头重排。
- 生成或编辑图片遵循当前宿主与用户指定的能力边界；在 Codex 中只用内置 `image_gen.imagegen`，失败时报告阻塞，不自动更换服务。封面文字由可核对排版补齐，数字与名称逐处检查。
- 按交付要求提供首帧、文件封面和平台比例独立图；只有约定首帧兼作封面时才要求一致，文件封面核对容器及平台支持。
- 字体和第三方素材记录作者、来源、许可与加工方式，保留授权要求的署名。对外包可省内部制作记录，但不能去掉必要来源和许可证。
- 完整解码、媒体参数与音量检查、封面要求、渲染日志检查按 `validation-matrix.md` 执行；多段拼接前确认规格兼容。
- 定稿保留唯一可运行重建入口及成片与源哈希记录，当前未解决问题留在工程。删旧产物须有授权，先留路径和字节数清单，不动源素材。
- scenes 作品需登记时按其 README 完成作品清单；不自动扩大到其他库、提交或发布。

## 参考分析与协作

- 参考先找镜头语法、信息密度、视线和阅读节奏，再找颜色材质。结论注明来源与局限，区分可借用关系与不兼容构图；参数换算到新时间表，不照抄秒数。
- 优先读取已提供材料和源码；截图、抽帧联系表及视觉复核仅在用户明确要求时进行。大改先做一个代表对象或短段小样。
- 自动化先验证短素材端到端，再投入全片。用日志增量、文件变化和进程状态判断进度，不把静默或退出码单独当产物结论。
- 子代理分工遵循当前宿主和用户授权；新聊天及向其他聊天发送消息需用户明确授权。交接写任务范围、文件所有权、数据接口、已验证命令、推进条件、失败信号及具体参考；主执行者负责时间表与入口集成。
- 覆盖交付文件先写临时名，检查后替换；保留基线。权限、资源和进程失败先查原因，遵循宿主审批路径，不自行绕过沙箱。
