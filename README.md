# Wise Motion

帮助不懂术语的人把动效需求讲清楚，并找到本地参考和源码。首版交付需求引导与参考匹配，不制作成品视频。

## 直接打开目录

立体翻页书位于“空间与透视”。右侧可切换时间演示与交互翻页，调整图片留白、圆角和书脊阴影；复制代码保留当前纸页设置。使用自绘本地插图和纸纹，按左右书页或方向键翻页。

打开 `catalog/index.html` 即可，无需启动服务器。目录有 177 个单个动作、53 个插画单图、14 个组合片段，以及逐条审查的 50 条历史配方、55 个案例；支持中文搜索、播放暂停、重播、时间定位、节奏比较和提示词／代码复制。独立结构示例保留整包相对目录即可使用；历史预览还需保留本机原工程目录，无需联网。

在目录选择动作，查看预览，调整节奏，再切换“提示词／代码”并复制。修改节奏会同步更新说明和两个输出；标准动作代码保存为包根目录的 `demo.html` 后直接打开；历史案例代码包含实际实现文件，按文件标题保留相对目录，并准备输出中列出的依赖包和素材输入。提示词只写可复刻的画面、动作和参数；来源、审查与验收信息保留在独立说明中。分类入口在搜索框右侧，鼠标移入搜索框打开菜单，也可点击图标或用键盘选择。输入搜索内容会清空当前分类，在当前标签页的全部参考中匹配；按 Esc 或点击搜索框的“×”清空搜索和分类。“×”在浅色模式为黑色，黑夜模式为白色。没有结果时，提示与清空按钮在侧栏内容区居中。筛选时保留当前预览，复制结果仅在操作后出现。

中央画板保持完整 16:9，大屏宽度最多 1440 像素，两侧留出动效切换按钮；手机画板略留白，切换按钮排在下方。点击两侧箭头或按键盘 ← / →，按当前筛选、搜索后的目录顺序切换，首尾循环；没有结果或仅有当前动作时按钮停用。输入、滑块、下拉菜单、输出页签和打开的目录抽屉保留各自键盘操作。按钮也可通过 Tab 聚焦后用回车或空格操作。

标准动作在有第三方来源时显示“来源”：有明确授权的代码改编写“AI 改编自……的代码”，明确的第三方效果参考写“效果参考……”。历史配方显示原作出处与抽象结论，并说明本机引用的范围。本地自有内容不展示自行开发声明，也不把使用动画库误写成动作来源。动画库及项目许可保留在版权与来源文档中。

布局使用一套尺寸、间距和文字规则，按可用宽度调整：

| 窗口宽度 | 布局与操作 |
| --- | --- |
| 1120 像素及以上 | 目录、预览、输出三栏。目录宽 256–336 像素，输出栏宽 288–360 像素，剩余空间交给预览；目录收起后保留 56 像素窄栏。 |
| 760–1119 像素 | 预览与输出两栏。目录改为品牌右侧按钮打开的抽屉，选动作后收起。 |
| 759 像素及以下 | 预览和播放条在前，说明、节奏、输出接在下方；目录仍用抽屉。页面自然纵向滚动。 |

左侧使用本地 website 的侧边栏结构：品牌与个人头像在前，主题和折叠按钮集中在品牌右侧。折叠按钮随状态切换朝左或朝右的箭头；收起后窄栏继续提供展开与主题操作。窄屏将这一组控件放在顶部，目录仍为抽屉。

预览保持 16:9，桌面同时按剩余高度限制画板尺寸。播放条材质接入 [Deepika 的开源背景折射](https://github.com/deepika-builds/liquid-glass)，源码和 MIT 许可随包保留。Chrome 等 Chromium 浏览器使用边缘折射，Safari、Firefox 保留磨砂回退。播放条采用紧凑的两行圆角面板：上方为两端时间和中性进度条，下方为居中的播放／暂停大按钮，重播和全屏放在两侧。桌面端面板浮在预览下沿之内，整条都压在画面上，边缘才有内容可弯；窄屏改为落在画面下方，避开本来就小的动效。两侧内容独立滚动，菜单按可用空间向上或向下展开。窄屏目录打开时限制背景交互，支持 Escape 关闭和焦点回到打开按钮。触屏主要按钮提供 44 像素的操作区域。

目录保留原面板比例与控件层次，普通示例的视觉统一参照本机展示片 56 秒的时间线：近黑底、暖白文字与细线，橙、紫、青等节点色只作必要强调；静态轻颗粒与暗角不增加播放开销。白天使用暖浅底，保持色相并调整对比。螺旋丸、牛皮纸等插画保留原配色与材质，不叠普通场景的纹理。纯英文和纯数字统一使用本地 Oswald Bold，中文正文和辅助标签使用思源黑体 Light，动效内中文主标题、分类与章节标题允许使用思源黑体 Bold。画板字号统一为 12、16、24、32、48、64 像素，细密刻度用 10 像素；图形缩放后按实际画板大小补偿。字形造型、词云和连续缩放的动作保留大小关系。分类按文字与编排、数值与图示、显现与展开、运动与循环、惯性与弹性、形变与生长、空间与透视、层次与重组、路径与连接、触发与传播、焦点与色光、场景与转换整理。“插画单图”独立为一个标签页，分为场域与能量、结构与网络、纸张与器物，不计入单个动作。历史案例保留原工程字体、字号及素材关系。

名称按可复用的运动机制来写，保持不同动作之间的区别。例如“斜升回正”描述进入与姿态变化，“双排对流”和“双排停靠”区分连续运动与落定，“汇聚与扩张”描述组合的先后关系。名称不绑定手机、年份、片名或提示词等示例内容；具体对象、原作名称和来源保留在说明中。分类以主要变化为准，形变与生长和空间与透视分开；明灭归焦点与色光，径向散射归运动与循环。旧名称保留为搜索词；目录标题、复制内容和说明文档使用统一的新名称，原有链接与源码入口保持稳定。

播放条试用 iOS 26 液态玻璃的网页材质近似：直接使用开源脚本的默认位移（边缘鼓起、三通道色散、中心磨砂），外观沿用其示例的薄渐变底、上缘高光、内缘反光、一像素玻璃边和投影，左上留一团静止反光。深浅外观只改这层薄着色。主播放键是面板上唯一常驻的圆形芯片，重播和全屏静止时是比播放键小的白色字形，悬停才浮起小玻璃。材质参考 [Apple 官方材质与浮动导航演示](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/)，两行布局与浮动位置参考用户提供的 iOS 锁屏播放器截图和 Apple Music 浮动导航。播放条透出当前主题的画面底色。这是网页背景折射的近似，未实现苹果原生自动背景识别与连续形变；其他面板保持原外观。浏览器不支持背景模糊，或开启增强对比、支持的降低透明度设置时，播放条回到实色。本次主题更新未进行浏览器截图验收，实际外观按验收步骤复核。

保留苹果人机交互指南中适用于网页的键盘焦点和外观显示设置，设计依据与适用边界见 [界面设计说明](references/apple-hig.md)。侧栏主题按钮只在深色和浅色之间切换，默认深色；支持增强对比。选择动作、插画、组合或历史案例时，中央预览默认从头自动播放；相关动作弹窗和复制保存的页面也从头播放，不依系统动效偏好降级或暂停，不显示相关提示或开关。手动暂停与时间定位保持有效；目录页面隐藏时暂停，返回后只恢复隐藏前正在播放的内容。列表用各自场景的静态缩略图，窗口变化后重新计算尺寸，不创建动画实例；切换动作释放旧实例。自编源码、字体与固定版本 Anime.js 全部在本地。

14 个组合均可逐层查看真实画面组成。右栏“相关动作”直接打开已登记的单个动作弹窗，并从头自动播放；主组合、播放位置、拆解选择和筛选保持不变。弹窗打开时暂停主画面，关闭后恢复此前的播放状态并释放弹窗播放器。

拆解顺序：先保留组合原画面，按实际对象与绘制代码拆出子动作，再对照动作库查重。几何、运动规则和时序机制真正一致才复用；缺少的独立动作与组合共用绘制函数，只创建自身需要的对象，不以整段组合隐藏其它图层代替拆解。双排反向滚动、双排滚动减速停靠和弧面卡片轮播作为普通动作。

新增的“笔墨与材质演变”保留精修后的纸底、书法、点线柱体、材质重组、球体、图鉴与字标收尾；七段也可单独播放，也可打开 [独立播放页](material-evolution-demo.html)。较大的字形数据和图片选中后才准备，静态缩略图只画代表时刻。原视频和截图不进入目录；字形轮廓与生成素材的权利说明见版权记录。

- [历史配方](references/history.md)：逐项审查、抽象关系、案例级源码、文稿节拍和原作时钟。

简单的本地辅助匹配不需要安装依赖：

```sh
node scripts/match.mjs "两排卡片反向持续滚动，不要轮播，不要停顿"
node scripts/match.mjs "卡片自然一点，轻轻进入"
```

词语匹配只辅助搜索。技能应按动作结构、禁项与因果关系推理；没有合适参考时说明缺口，再定向联网。

## 修改与验证

标准动作的权威定义是 `catalog/registry.json`。历史审查的权威记录位于私有状态目录 `../../state/wise-motion/history/`，包含来源快照、源码依据和逐项对应表。构建时一起生成页面数据、244 项标准说明和历史审查报告，不手改生成文件。

```sh
node scripts/build.mjs
node scripts/check.mjs
npm ci --ignore-scripts
npm test
```

检查用 Node.js 24.19.0 和固定开发依赖 jsdom 30.1.1。开发依赖只模拟页面结构进行功能检查，不启动浏览器，不进行截图或视觉验收。普通使用目录无需这些依赖。

自动检查覆盖字段、组合与历史对应关系、案例级源码路径、生成文件一致性、静态资源本地化、匹配差异、244 项标准示例的反复定位，以及异步原作加载、案例切换、播放接口和资源释放。保留目录抽屉、菜单、键盘与缩略图检查。自动检查不代替真实浏览器体验，人工体验按 [验收步骤](tests/manual.md) 直开完成。

目录新增文字后，用 `python3 scripts/build-fonts.py` 补齐三种字重的本地字体子集，再用 `python3 scripts/build-fonts.py --check` 核对全部汉字覆盖。构建需要本机思源黑体和 FontTools；字体保留 OFL 许可并使用 Wise Motion Sans 独立族名。界面正文及列表名称使用细体，品牌、当前动作标题和章节标题保留粗体。
