# Wise Motion

先结合上下文理解用户意图，转译为画面变化、动作关系与约束，再匹配本地动效，通过设计、改良、发散和随机组合形成方案。按请求交付参考说明、静态画布、可播放动效或视频。新动效及新视频中的动效统一使用 Remotion；目录界面、静态画布和普通网页不受此限制。维护已有非 Remotion 工程时保留原栈，不自动迁移。

设计与源码选择见 [导演设计方法](references/director-design.md)，逐个开发与整合见 [阶段制作方法](references/pipeline-methodology.md)。

## 直接打开目录

正式目录的预览已由 Remotion 逐帧驱动，保留原绘制、材质和运动公式；路径和目录界面保持不变。可复用组件、素材安装与视频导出见 [Remotion 使用说明](REMOTION.md)。迁移基准、对照片和回退记录单独保留在维护目录。

“黄金矩形递归生长”以瀑布网格、字符雨幕、打铁花与黄金分割递归组成完整片段，时长约21.13秒。旧入口和书签仍定位到这一新版；组合拆解、关联动作、复制代码与视频导出共用同一套实际绘制。

本地目录直接通过 Remotion 播放当前源码，无需服务器。旧版专用视频缓存与播放入口已撤下，避免缓存画面与源码不一致。

立体翻页书位于“空间与透视”。右侧可切换时间演示与交互翻页，调整图片留白、圆角和书脊阴影；复制代码保留当前纸页设置。使用自绘本地插图和纸纹，按左右书页或方向键翻页。

打开 `catalog/index.html` 即可，无需启动服务器。目录有 274 个单个动作、61 个插画单图、25 个组合片段，历史目录已清空；支持中文搜索、播放暂停、重播、时间定位、节奏比较和提示词／代码复制。正式目录无需本机历史工程；原作与迁移依据单独保留供追溯。

在目录选择动作，查看预览，调整节奏，再切换“提示词／代码”并复制。修改节奏会同步更新说明和两个输出；标准动作代码提供 Remotion 组件与完整依赖、素材安装步骤；自带帧组件的条目提供独立工程源码，按复制结果的文件名保存并运行。提示词只写可复刻的画面、动作和参数；来源、审查与验收信息保留在独立说明中。分类入口在搜索框右侧，鼠标移入搜索框打开菜单，也可点击图标或用键盘选择。输入搜索内容会清空当前分类，在当前标签页的全部参考中匹配；按 Esc 或点击搜索框的“×”清空搜索和分类。“×”在浅色模式为黑色，黑夜模式为白色。没有结果时，提示与清空按钮在侧栏内容区居中。筛选时保留当前预览，复制结果仅在操作后出现。

中央画板保持完整 16:9，大屏宽度最多 1440 像素，两侧留出动效切换按钮；手机画板略留白，切换按钮排在下方。点击两侧箭头或按键盘 ← / →，按当前筛选、搜索后的目录顺序切换，首尾循环；没有结果或仅有当前动作时按钮停用。输入、滑块、下拉菜单、输出页签和打开的目录抽屉保留各自键盘操作。按钮也可通过 Tab 聚焦后用回车或空格操作。

标准动作在有第三方来源时显示“来源”：有明确授权的代码改编写“AI 改编自……的代码”，明确的第三方效果参考写“效果参考……”。已迁入条目的原作出处与抽取范围保留在来源说明和私有历史记录中。本地自有内容不展示自行开发声明，也不把使用动画库误写成动作来源。动画库及项目许可保留在版权与来源文档中。

布局使用一套尺寸、间距和文字规则，按可用宽度调整：

| 窗口宽度 | 布局与操作 |

左侧使用本地 website 的侧边栏结构：品牌与个人头像在前，主题和折叠按钮集中在品牌右侧。折叠按钮随状态切换朝左或朝右的箭头；收起后窄栏继续提供展开与主题操作。窄屏将这一组控件放在顶部，目录仍为抽屉。

预览保持 16:9，桌面同时按剩余高度限制画板尺寸。播放条材质接入 [Deepika 的开源背景折射](https://github.com/deepika-builds/liquid-glass)，源码和 MIT 许可随包保留。Chrome 等 Chromium 浏览器使用边缘折射，Safari、Firefox 保留磨砂回退。播放条采用紧凑的两行圆角面板：上方为两端时间和中性进度条，下方为居中的播放／暂停大按钮，重播和全屏放在两侧。桌面端面板浮在预览下沿之内，整条都压在画面上，边缘才有内容可弯；窄屏改为落在画面下方，避开本来就小的动效。两侧内容独立滚动，菜单按可用空间向上或向下展开。窄屏目录打开时限制背景交互，支持 Escape 关闭和焦点回到打开按钮。触屏主要按钮提供 44 像素的操作区域。

目录保留原面板比例与控件层次，普通示例的视觉统一参照本机展示片 56 秒的时间线：近黑底、暖白文字与细线，橙、紫、青等节点色只作必要强调；静态轻颗粒与暗角不增加播放开销。白天使用暖浅底，保持色相并调整对比。螺旋丸、牛皮纸等插画保留原配色与材质，不叠普通场景的纹理。纯英文和纯数字统一使用本地 Oswald Bold，中文正文和辅助标签使用思源黑体 Light，动效内中文主标题、分类与章节标题允许使用思源黑体 Bold。画板字号统一为 12、16、24、32、48、64 像素，细密刻度用 10 像素；图形缩放后按实际画板大小补偿。字形造型、词云和连续缩放的动作保留大小关系。单个动作按入场、文字、数据、扫描、布局、滚动、路径、回弹、形变、立体、强调、光效、反馈、粒子和转场分组。插画素材按自然与天体、流场与能量、几何与网络、物件与角色、界面与读数分组；组合片段按文字与叙事、界面与演示、图形与材质分组。每个条目按主要用途归入一组，分类筛选只展示当前页签的分组。历史来源记录保留原工程字体、字号及素材关系，不作为当前页面入口。

名称用简短中文说明可复用的动作，通常为四到八个字。例如“斜升回正”说明进入与姿态变化，“双排反向滚动”和“双排反向停靠”区分循环与落定，“匀速缓动对照”说明速度差异，“文字汇聚光核扩散”说明组合的先后关系。动作名称不绑定手机、年份、片名或提示词等示例内容；插画名称直接说明图形或物件，具体示例和来源保留在说明中。分类以主要用途和变化为准：数据图表与扫描信号分开，重点强调与光效氛围分开，粒子释放和拖尾归粒子与流动；单画面的布局调整不归入画面转场。旧名称保留为搜索词；目录标题、复制内容和说明文档使用统一的新名称，原有链接与源码入口保持稳定。

播放条试用 iOS 26 液态玻璃的网页材质近似：直接使用开源脚本的默认位移（边缘鼓起、三通道色散、中心磨砂），外观沿用其示例的薄渐变底、上缘高光、内缘反光、一像素玻璃边和投影，左上留一团静止反光。深浅外观只改这层薄着色。主播放键是面板上唯一常驻的圆形芯片，重播和全屏静止时是比播放键小的白色字形，悬停才浮起小玻璃。材质参考 [Apple 官方材质与浮动导航演示](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/)，两行布局与浮动位置参考用户提供的 iOS 锁屏播放器截图和 Apple Music 浮动导航。播放条透出当前主题的画面底色。这是网页背景折射的近似，未实现苹果原生自动背景识别与连续形变；其他面板保持原外观。浏览器不支持背景模糊，或开启增强对比、支持的降低透明度设置时，播放条回到实色。本次主题更新未进行浏览器截图验收，实际外观按验收步骤复核。

保留苹果人机交互指南中适用于网页的键盘焦点和外观显示设置，设计依据与适用边界见 [界面设计说明](references/apple-hig.md)。侧栏主题按钮只在深色和浅色之间切换，默认深色；支持增强对比。选择动作、插画或组合时，中央预览默认从头自动播放；相关动作弹窗和复制保存的页面也从头播放，不依系统动效偏好降级或暂停，不显示相关提示或开关。手动暂停与时间定位保持有效；目录页面隐藏时暂停，返回后只恢复隐藏前正在播放的内容。列表用各自场景的静态缩略图，窗口变化后重新计算尺寸，不创建动画实例；切换动作释放旧实例。自编源码、字体、Remotion 播放器与固定版本 Anime.js 全部在本地，Anime.js 保留原缓动计算。

插画素材保留自身动作。当前 61 个插画中，60 个带动作；斜放手机的空屏机身保持静态。右栏“插画包含的动作”可直接打开对应动作。相同运动方式优先归入已有动作并增加插画示例；缺少的动作独立登记并共用实际绘制。雨伞关联原六段动作，月亮沿用光面渐满；玻璃卡、汽车、太阳和种子复用已有动作，冠毛展开转向与长条扫过独立纳入。

25 个组合均可逐层查看真实画面组成。右栏“相关动作”直接打开已登记的单个动作弹窗，并从头自动播放；主组合、播放位置、拆解选择和筛选保持不变。弹窗打开时暂停主画面，关闭后恢复此前的播放状态并释放弹窗播放器。

拆解顺序：先保留组合原画面，按实际对象与绘制代码拆出子动作，再对照动作库查重。几何、运动规则和时序机制真正一致才复用；缺少的独立动作与组合共用绘制函数，只创建自身需要的对象，不以整段组合隐藏其它图层代替拆解。双排反向滚动、双排滚动减速停靠和弧面卡片轮播作为普通动作。

新增的“笔墨与材质演变”保留精修后的纸底、书法、点线柱体、材质重组、球体、图鉴与字标收尾；七段也可单独播放；完整组合统一从 [正式目录](catalog/index.html) 打开。较大的字形数据和图片选中后才准备，静态缩略图只画代表时刻。原视频和截图不进入目录；字形轮廓与生成素材的权利说明见版权记录。

“玻璃卡片显现折射”采用黑银光学风格，完整组合为7.2秒。六张玻璃卡使用三轴旋转、透视投影、十像素圆角侧壁与随朝向移动的反光；音乐、天气和控制中心按0.85秒间隔来到前景，以连续滑行和展示时轻微漂移衔接，其余卡退到两侧，随后六卡展开并让对话卡承接凸泡。凸泡对实际合成画面采样，放大文字后在 MOTION 的第一个 O 中心淡出，由原生字形接管，字标统一采用“字色依次轮换”的 Helvetica Neue Bold 原生字形与字距，双语短句随后出现。背景、卡面、侧壁和控件只用黑白灰，凸泡保持无深色内圈与整圈描边。六张卡也分别收录于插画，透明背景下以固定侧转姿态呈现厚度；组合内语音从左向右进场并显示波形，音乐封面涟漪扩散、进度推进，亮度与音量错开变化，对话回复逐行逐字输出；独立插画保持固定完整画面。完整组合、独立空间动作、插画、目录预览和导出共用绘制源码。

“金属弹开汇聚成字”落地后六球沿高低、左右、前后不同方向大幅散开，再用0.76秒从各自位置沿弧线直接汇向中心；中心短促压聚后向四周散射六色金属粒子，再由同一批粒子回收到字面，在收拢末段形成光滑 MOTION，最后扫光。“落地分裂六球回弹”“中心汇聚散射成字”“抛光金属字面扫光”可分别预览和复制。完整组合为 5.3 秒，两个 O 为圆形；无需原演示或视频素材。

## 修改与验证

标准动作的权威定义是 `catalog/registry.json`。日常构建生成页面数据、标准说明和播放器，不读取或改写源码外的历史档案。历史审查的权威记录位于私有状态目录 `../../state/wise-motion/history/`；只有修改这些记录时才运行 `npm run build:history`，用 `npm run check:history` 核对。生成文件不手工维护。

```sh
npm ci
npm run build
npm test
npm run render -- stagger-in stagger-in.mp4
```

构建使用固定版本的 React、Remotion 和打包工具；`npm run build` 同时生成目录数据、组件和本地播放器。`npm run check` 检查结构与字体覆盖；`npm test` 另含原作迁移与绘制公式检查，需要保留私有历史档案。实际浏览器与视频检查另行进行。目录本身仍可直接打开，无需安装依赖或启动服务。视频导出会使用 Remotion 临时服务。

自动检查覆盖字段、组合与历史对应关系、案例级源码路径、生成文件一致性、静态资源本地化、匹配差异、360 项标准示例的反复定位，以及异步原作加载、案例切换、播放接口和资源释放。保留目录抽屉、菜单、键盘与缩略图检查。自动检查不代替真实浏览器体验，人工体验按 [验收步骤](tests/manual.md) 直开完成。

实时预览只在首次准备及新素材尚未就绪时等待，无声目录不初始化音频播放；普通绘制由 Remotion 时钟推进，视频导出仍等待每一帧及画面提交完成。胶囊、绿洲及流线复用固定几何、字宽和绘图数据，保持原画幅、细节数量与运动公式。

预览按条目加载原绘制文件及其声明的依赖，组合按原顺序加载相关绘制；缩略图绘制失败会明确显示原因。需要全量核对真实实现和依赖时，运行 `node scripts/audit-catalog.mjs --output ../../maintenance/wise-motion-performance/current.json`。检查使用 Remotion 配套浏览器直接打开本地文件，不启动服务、不截图，覆盖全部条目与变体的实际绘制、重复定位、加载前后画面数据、复制代码及打包素材。它不代替完整动画的人工观看。

目录新增文字后，用 `python3 scripts/build-fonts.py` 补齐三种字重的本地字体子集，再用 `npm run check:fonts` 核对全部汉字覆盖；该项已纳入日常检查和测试。补字会保留已有字符。补字需要本机思源黑体和 FontTools；日常字体检查只需要 Python 和 FontTools，不读取原始字体。字体保留 OFL 许可并使用 Wise Motion Sans 独立族名。界面正文及列表名称使用细体，品牌、当前动作标题和章节标题保留粗体。
