# Wise Motion

帮助不懂术语的人把动效需求讲清楚，并找到本地参考和源码。首版交付需求引导与参考匹配，不制作成品视频。

## 直接打开目录

打开 `catalog/index.html` 即可，无需启动服务器。目录有 72 个单个动作、6 个组合片段，以及逐条审查的 289 条历史配方、311 个案例；支持动画／文稿筛选、中文搜索、播放暂停、重播、时间定位、节奏比较和提示词／代码复制。独立结构示例保留整包相对目录即可使用；历史预览还需保留本机原工程目录，无需联网。

在目录选择动作，查看预览，调整节奏，再切换“提示词／代码”并复制。修改节奏会同步更新说明和两个输出；代码保存为包根目录的 `demo.html` 后直接打开。分类入口在搜索框右侧，鼠标移入搜索框打开菜单，也可点击图标或用键盘选择。筛选时保留当前预览，复制结果仅在操作后出现。

中央画板保持完整 16:9，大屏宽度最多 1440 像素，两侧留出动效切换按钮；手机画板略留白，切换按钮排在下方。点击两侧箭头或按键盘 ← / →，按当前筛选、搜索后的目录顺序切换，首尾循环；没有结果或仅有当前动作时按钮停用。输入、滑块、下拉菜单、输出页签和打开的目录抽屉保留各自键盘操作。按钮也可通过 Tab 聚焦后用回车或空格操作。

标准动作在有第三方来源时显示“来源”：有明确授权的代码改编写“AI 改编自……的代码”，明确的第三方效果参考写“效果参考……”。历史配方显示原作出处与抽象结论，并说明本机引用的范围。本地自有内容不展示自行开发声明，也不把使用动画库误写成动作来源。动画库及项目许可保留在版权与来源文档中。

布局使用一套尺寸、间距和文字规则，按可用宽度调整：

| 窗口宽度 | 布局与操作 |
| --- | --- |
| 1120 像素及以上 | 目录、预览、输出三栏。目录宽 256–336 像素，输出栏宽 288–360 像素，剩余空间交给预览；目录收起后保留 56 像素窄栏。 |
| 760–1119 像素 | 预览与输出两栏。目录改为品牌右侧按钮打开的抽屉，选动作后收起。 |
| 759 像素及以下 | 预览和播放条在前，说明、节奏、输出接在下方；目录仍用抽屉。页面自然纵向滚动。 |

左侧使用本地 website 的侧边栏结构：品牌与个人头像在前，主题和折叠按钮集中在品牌右侧。折叠按钮随状态切换朝左或朝右的箭头；收起后窄栏继续提供展开与主题操作。窄屏将这一组控件放在顶部，目录仍为抽屉。

预览保持 16:9，桌面同时按剩余高度限制画板尺寸。播放条材质接入 [Deepika 的开源背景折射](https://github.com/deepika-builds/liquid-glass)，源码和 MIT 许可随包保留。Chrome 等 Chromium 浏览器使用边缘折射，Safari、Firefox 保留磨砂回退。播放条采用紧凑的两行圆角面板：上方为两端时间和中性进度条，下方为居中的播放／暂停大按钮，重播和全屏放在两侧。桌面端面板浮在预览下沿之内，整条都压在画面上，边缘才有内容可弯；窄屏改为落在画面下方，避开本来就小的动效。两侧内容独立滚动，菜单按可用空间向上或向下展开。窄屏目录打开时限制背景交互，支持 Escape 关闭和焦点回到打开按钮。触屏主要按钮提供 44 像素的操作区域。

视觉参考 [Amicro](https://amicro.vercel.app/Anime) 的中性配色、边界与留白，以及 [Amotion 编辑器](https://www.amotion.app/editor) 的面板比例和控件层次。保留个人头像；示例卡片使用白底深字，场景使用黑白灰，选中状态由底色和细边界区分。文字使用本地思源黑体子集，默认 Light、小标题 Regular、品牌及章节标题 Bold；数字使用本地 Outfit。搜索、下拉框和数值框统一为 12 像素，字色跟随“速度变化”，输出正文不大于“代码块”标签。

播放条试用 iOS 26 液态玻璃的网页材质近似：直接使用开源脚本的默认位移（边缘鼓起、三通道色散、中心磨砂），外观沿用其示例的薄渐变底、上缘高光、内缘反光、一像素玻璃边和投影，左上留一团静止反光。深浅外观只改这层薄着色。主播放键是面板上唯一常驻的圆形芯片，重播和全屏静止时是比播放键小的白色字形，悬停才浮起小玻璃。材质参考 [Apple 官方材质与浮动导航演示](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/)，两行布局与浮动位置参考用户提供的 iOS 锁屏播放器截图和 Apple Music 浮动导航。网站的黑白灰背景透过玻璃后仍为中性色，不具备参考图中封面与壁纸的色彩变化。这是网页背景折射的近似，未实现苹果原生自动背景识别与连续形变；其他面板保持原外观。浏览器不支持背景模糊，或开启增强对比、支持的降低透明度设置时，播放条回到实色。已在 Chromium 上逐档截图核对深浅外观、折射带、悬停与窄屏回退，其余按验收步骤复核。

保留苹果人机交互指南中适用于网页的键盘焦点和系统显示设置，设计依据与适用边界见 [界面设计说明](references/apple-hig.md)。侧栏主题按钮可选择深色、浅色或跟随系统；支持增强对比。系统设置“减少动态效果”时，当前预览默认定位到可见画面并暂停，可手动播放。列表用各自场景的静态缩略图，窗口变化后重新计算尺寸，不创建动画实例；切换动作释放旧实例。自编源码、字体与固定版本 Anime.js 全部在本地。

## 技能入口与选型

- [SKILL.md](SKILL.md)：短技能正文，明确只手动调用。
- [需求方法](references/method.md)：描述动作、拆解关系、现实类比和统一动作说明。
- [轻量索引](references/index.md)：按行为找到候选，只读选中效果的详细说明与源码。
- [来源与许可](references/sources.md)：各类来源的核实结论与内置边界。
- [播放接口](references/runtime-interface.md)：可定位、可重复演示、可释放资源的动作参考。
- [历史配方](references/history.md)：逐项审查、抽象关系、案例级源码、文稿节拍和原作时钟。

简单的本地辅助匹配不需要安装依赖：

```sh
node scripts/match.mjs "两排卡片反向持续滚动，不要轮播，不要停顿"
node scripts/match.mjs "卡片自然一点，轻轻进入"
```

词语匹配只辅助搜索。技能应按动作结构、禁项与因果关系推理；没有合适参考时说明缺口，再定向联网。

## 修改与验证

标准动作的权威定义是 `catalog/registry.json`。历史审查的权威记录位于私有状态目录 `../../state/wise-motion/history/`，包含来源快照、源码依据和逐项对应表。构建时一起生成页面数据、78 项标准说明和历史审查报告，不手改生成文件。

```sh
node scripts/build.mjs
node scripts/check.mjs
npm ci --ignore-scripts
npm test
```

检查用 Node.js 24.19.0 和固定开发依赖 jsdom 30.1.1。开发依赖只模拟页面结构进行功能检查，不启动浏览器，不进行截图或视觉验收。普通使用目录无需这些依赖。

自动检查覆盖字段、组合与历史对应关系、案例级源码路径、生成文件一致性、静态资源本地化、匹配差异、78 项标准示例的反复定位，以及异步原作加载、案例切换、播放接口和资源释放。保留目录抽屉、菜单、键盘与缩略图检查。没有自动截图或真实浏览器验收，人工体验按 [验收步骤](tests/manual.md) 直开完成。

目录新增文字后，用 `python3 scripts/build-fonts.py` 补齐三种字重的本地字体子集，再用 `python3 scripts/build-fonts.py --check` 核对全部汉字覆盖。构建需要本机思源黑体和 FontTools；字体保留 OFL 许可并使用 Wise Motion Sans 独立族名。界面正文及列表名称使用细体，品牌、当前动作标题和章节标题保留粗体。
